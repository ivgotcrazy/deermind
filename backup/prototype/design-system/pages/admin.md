# DeerMind · 管理员端覆盖（Admin Mode · Evidence Debugger）

> 覆盖：`MASTER.md`（本文件规则优先于 Master）。
> 应用方式：原型中 `.admin-mode` 作用域；生产 `admin_web`（Vue3/Vite）入口。
> 说明：管理员端是**看板级调试工具**（Evidence Debugger），面向产品/研发自省，非家长使用。
> 目的：可解释性 —— 每一个掌握度/决策都能被追溯：看到证据 → 估计器 → 决策理由。

## 风格

数据后台（Dashboard）范式 —— 表格、状态徽章、时间线、KPI 卡、Bento 布局。信息密度允许高于家长端，但仍克制：单屏一主题、无动画噪音。

## 令牌覆盖

| 令牌 | 值 | 说明 |
|---|---|---|
| `--radius-card` | 8px | 紧凑卡片（信息密度优先） |
| `--radius-btn` | 6px | 小按钮 |
| `--radius-input` | 6px | 输入框 |
| `--card-bg` | `#FFFFFF` | 白卡 |
| `--btn-weight` | 600 | 对齐 MASTER |
| `--shadow-card` | 0 1px 3px rgba(16,24,40,.06) | 极轻投影 |
| 字体 | system-ui / 苹方 / 微软雅黑 | 去卡通感，等宽数字（表格对齐） |
| 背景 | `#F8FAFC`（slate-50） | 数据工作台底色 |

## 布局

- **桌面优先**：左侧固定导航 Rail（图标 + 文字）+ 右侧内容区
- **内容区**：顶部页标题 + 说明；下方 Bento 卡片网格（KPI 卡 → 主表 → 详情面板）
- 断点 <768px：导航折叠为顶部横向 Tab

## 组件规格

- **KPI 卡**：label + 大数字 + 同比/说明；边框 1px slate-200
- **状态徽章（四态）**：
  - 未接触 `#F1F5F9` / 文字 `#64748B`
  - 学习中 `#FEF3C7` / `#B45309`
  - 短期掌握 `#ECFDF5` / `#059669`（青绿）
  - 稳定掌握 `#DCFCE7` / `#15803D`（绿）
- **表格**：表头 12px 600 slate-500；行 13px；hover 高亮；数值右对齐（等宽）
- **时间线（证据/决策）**：左侧竖线 + 时间戳 + 类型徽章 + 说明
- **规则配置**：通用表单（分段 label + 数字/时间输入 + 开关），保存按钮

## 数据标注

所有 estimate / confidence / stability 均为**演示值**，页面脚注统一标注：
「演示数据 · 算法见《系统设计.md》」。

## 反模式

- 禁止把数值暴露给学生端（学生端只露四态，PRD §6.7）
- 禁止在管理员端引导任何"人为改掌握度"的入口（只读调试 + 规则配置）
- 禁 emoji 装饰；图标用线框 SVG
