# DeerMind 单题受限原型修订 v0.2

日期：2026-10-07。本次依照用户接受的“一次集中修正加一次完整验收”安排，对已查明的接口缺陷和作答与请求混淆作一次明确修订。处理链仍为 Observation 生成、职责分类、算术映射、语义校验、正式提交、Policy 生成与校验、受限提示展示及第二轮处理。串行规则、权限、正式提交条件、两个登记提示、六类十二个会话和原验收门槛均保留。

新协议为 Observation v14，新增候选片段编号表示。程序按标点和换行生成无损定位片段，保留完整原文、字段和起止位置。分片不判断句意、职责、正确性或请求类别，模型可以组合相邻片段表达完整判断。职责分类、算术映射和校验引用通过编号选择原文，不再要求模型重复抄写候选段落。未知、重复、乱序、跨字段、缺失或重叠的覆盖仍被拒绝；单个表达式必须位于其所属分段内。两个相同字符串的出现位置拥有不同编号。程序不会纠正模型引用的意思，也不会把存在于原文等同于获得语义支持。

数值表示增加 ScalarValue，用于已有的单个数值，例如提交结果 120。它没有虚构的运算符和操作数，机械检查只核实数值格式；是否符合原文、是否为最终答案、是否正确仍由必需的语义检查判断。NumericAssertion 只表示完整的二元算式，其操作数和结果不得为空；UnevaluatedExpression 表示只有运算而没有声明结果的情况，不自动补算；无法映射的关系继续保持 UNRESOLVED。不同类型的结构约束直接写入输出 schema。

生成和校验规则明确区分学习者已写出的作答与其对系统回复的要求。“不要给答案”不能删除已有的计算结果；终止于总价的计算不必额外写上“最终答案”标签才算提交结果。同时，只有中间步骤且明确未完成的作答不能被补成完整答案。模型必须从原始任务和作答作出这些判断，不通过关键词路由。规则加入不同数字的正反例；这属于可验证的提示修订，不保证模型一定理解正确。

本地准备覆盖新接口的结构检查、旧路径回归和新版本 M1–M7，并使用上轮保存的候选和算术输出构造容量及表示检查。历史返回只作为离线材料；测试中人工指定的类型和来源不冒充真实模型判断，不进入真实批次。原先十二个补发响应接回旧后端时，有五个 Observation 能提交，六个因候选文本抄写不一致被拒绝，一个被实际检查判为 FAIL；这些结果再次说明返回格式合规不等于后端通过。该检查没有发送新请求，也没有执行 Policy。

真实阶段固定使用 DeepSeek Flash、beta strict 输出、thinking disabled、temperature 0、64,000 字符本地消息上限、4,096 输出 token、单次最多 60 秒。仍为十二个会话共二十四轮，最多 168 次调用、45 分钟；无网络重试、样本替换或批次内改规则。普通质量失败继续其他独立样本；机械边界失效或总预算耗尽时停止。保留全部失败和未运行项。

验收沿用 v0.1：M1–M7 全部通过，没有 H 类机械越界或 C 类已接受严重内容错误，至少十个完整会话成功且六类各至少一个。作者一次检查实际生成、校验、提交、展示和第二轮帮助记录，不能只计模型 PASS，也不把正确拒绝坏候选当成正常交互成功。修正最多四小时，真实调用最多四十五分钟，作者评审最多一小时，汇总最多十五分钟；达到上限或评审结束即给出 GO_INTERNAL_PROTOTYPE、NO_GO 或 INCOMPLETE，不自动追加下一轮。

原协议、原样本结果和冻结包保留。共享 Runtime 的新分支只由新协议显式启用，并在正式提交时重新展开编号、重算算术和核对候选绑定。旧源码保存在 `src/spike/reports/source-baseline-single-task-v2-20261007/`。本修订不改变历史 9/17、A2 和 Gate E/F，不跳过 Observation，不实现已搁置的 Policy v6 reviewer。
