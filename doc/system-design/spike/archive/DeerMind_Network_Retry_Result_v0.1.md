## 排除网络后实际卡在哪里

**正确判断被职责规则拒绝。** T01 第一轮的学习者作答是“42÷6＝7，7×15＝105”。生成的 Observation 正确写出“该计算正确……提交的最终结果105元与任务一致”。职责分类调用却返回 `evidence_inference`，理由是系统正在判断学习者结果是否与任务一致。算术检查通过，后续语义校验的七个项目也都返回 PASS，但程序按既定规则将 `evidence_inference` 判为 FAIL，拒绝提交，Policy 因而没有开始。

这不是数学不会算。当前职责提示词一方面允许局部算术和任务观察，另一方面把“系统声明某事支持或反驳学习者主张或掌握信念”都归入禁止类别。普通作答正确性判断也可能落入后一句，规则边界存在重叠。上述原文和分类理由支持“规则写法有责任”的解释，但本次没有修改规则做对照实验，不能声称已经量化了它对全部分类失败的贡献。十一轮最终校验拒绝中，十轮包含这一禁止类别；不能全部简单归咎于模型幻觉。

**转述错误算式被当成认可错误算式。** 例如 T08 第一轮的 Observation 报告学习者写了“7×15＝120”，并明确纠正为 105。提取器却把被转述的错误算式标为 `asserted_true`，计算器因此返回 FAIL。按现有合同，应标为 `reported_only`。十一轮最终校验拒绝中，三轮包含这种算术立场问题，与前述职责问题重叠两轮，所以不是十三个独立失败。

**引用与格式接口仍有问题。** 四轮的校验返回把多个不相邻候选片段放在同一组引用中，程序按连续性要求拒绝。另有 T03 第二轮的 Policy 引用了实际存在的 AssistanceContext，引用空间是 `execution`，但 Policy schema 只允许 `fact`、`canonical`、`derived`，因此返回被拒绝。这里既有输出违反合同，也有输入提供了辅助上下文、输出引用合同却不能直接表达它的接口限制；不应解释为网络故障或数学错误。

复核也没有完全可靠。T09 第一轮的候选承认学习者写出了 120，却没有明确判断该终值是否符合原题；final_result 校验理由自己指出了这一缺项，状态仍给 PASS。该轮因其他检查失败，没有提交。这个记录支持“复核仍会漏项”，不支持把原始 PASS 数量当作内容正确率。

## 重试规则及中断说明

模型仍为 DeepSeek Flash，使用原 beta endpoint、temperature 0、关闭 thinking、4096 输出 token、单请求 60 秒、消息上限 64,000 字符。Observation v14、Policy v2、任务输入和共享运行时源码保持冻结。只对超时、TLS、DNS、连接中断、响应未读完及 429/500/502/503/504 等明确传输错误重试；同一请求最多三次，间隔 2 秒、5 秒。重试保留原消息及 schema，不修改模型内容；格式或语义失败不重试。仍然严格串行，所有尝试都记账。

首次补跑在 45.767 秒、6 次调用后因补跑代码的日志错误中止：重试记录新增了 `session`，原批次记录器又传入同名参数，触发 `TypeError: ... got multiple values for keyword argument 'session'`。此前七项测试只测适配器，没有覆盖它与完整批次记录器的组合。这是补跑实现与测试覆盖不足的责任。

修复仅将附加标记放入 `retry_context`，增加完整十八轮的本地集成检查，并在意外中断时从已保存日志保留逐轮状态。八项本地检查通过后重新启动；模型提示和共享运行时没有修改。原中止目录、旧代码、六次调用全部保留，其中 T01 第一轮的 `OutputSchemaMismatch` 仍是失败证据，其余十七轮记为未运行；原中止汇总的空 rows 不能解释为零未运行。

本次重启后没有传输失败，因此真实请求没有触发重试。中止批次的一次 `ProviderIncompleteRead` 曾在第二次尝试获得响应；日志错误随后发生。包含中止批次在内，共 83 次调用、326.805 秒实际运行时间，约 5 分 27 秒，均计入最初的 378 次调用和 45 分钟上限；这不是包含会话中断、代码修复和报告工作的总历时。最大实际消息为 33,193 字符，没有本地长度拦截。

## 结论与证据

网络未知项已与语义及接口问题分开。本次无需网络失败作为理由，就能确定**冻结的当前实现没有达到原型门槛**。可确认的工程问题是职责规则边界重叠、转述立场映射、引用表示限制和复核漏项；这些结果不能推出 LLM 语义方案无解，也不能证明总体架构失败。结束本次补跑，保留历史 9/17、A2 和 Gate E/F 状态，不再自动重复同一配置。
