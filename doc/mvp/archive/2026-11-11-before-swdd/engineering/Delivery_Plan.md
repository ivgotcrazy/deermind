**职责。** 将工程设计转为有依赖、有限范围、交付物和退出条件的实施计划，安排必要技术验证、联调及整册验收。

**输入。** [工程入口的E01—E07](README.md#4-已确认范围下的工程实施顺序)、[PRD v0.23](../../../m1/PRD.md)、[验证计划 v0.4](../../../m1/validation/Validation_Plan.md)；共同设计输入为本目录五份技术设计及其待决／验证事项。

**预期输出与接收者。** 实施依赖与工作项、分步交付及测试安排、接收清单和部署交接计划；供后续编码、验证和实际交付报告使用。

**边界。** 本轮形成首条实现链的计划草案，不排未获依据的工期、不启动验证或编码。质量指标和测量方法引用validation；实际执行结果未来进入报告，不在计划中预填通过。

本轮展开§2–3的验证和复用安排，其余仍标待设计。其余专题已形成相应局部草案，尚未获整体工程接收。共同范围、唯一维护位置和推进顺序见[工程入口](README.md)，产品规则承接见[对应表§3.1](README.md#31-产品规则到工程章节的对应)。

## 2. 先行技术验证

先审阅[架构§6](Engineering_Design.md#6-技术选择复用与关键风险)的TECH-01—06，再执行下表的限定验证。本轮只写计划；先用假模型与真实数据库验证确定性机制，再验证真实LLM语义质量。

| 编号 | 输入与故障点 | 预期结果及检查依据 |
| --- | --- | --- |
| ENG-V01 重复提交 | 同轮同client_submission_id并发提交；同ID改载荷或跨轮复用；新ID再次提交已结束轮 | 同载荷返回原提交，无重复事实／评价／job；改载荷冲突；跨轮复用冲突，已结束轮不可覆盖。核对响应、行数和唯一约束 |
| ENG-V02 认领与迟返 | 两worker抢同job；首worker暂停至过期、重领后再迟返 | 仅有效租约提交，无重复概率更新／消息。保存尝试记录与事件计数 |
| ENG-V03 中断恢复 | 事实事务提交前退出、提交后响应前退出、结果提交后通知前退出 | 分别完整回滚、重试读原提交、从持久结果恢复；不依赖内存通知和第二条触发路径 |
| ENG-V04 评价顺序 | 同空间作答／教学机会／作答顺序登记，首项技术失败；另一个空间正常处理 | 本空间后续评价等原序重试，预算耗尽须经受控追加额度才能继续且保留累计用量，其他空间运行；合法未知可结束不更新，技术失败不能冒充未知跳过 |
| ENG-V05 数值资格 | 内容§4.19 fixture、非法参数、阈值边界、重复Evidence、无归因、迁移／保持L=0 | 调实际numerics核对结果；不以缺证代入y=0，不跨分项复制成功；目标按未舍入观测值与适用证据判断 |
| ENG-V06 求助展示 | 独立轮内实质求助、含糊请求、模型输出提示；断线恢复 | 实质帮助前结束轮；含糊请求中性澄清；未经检查token不直出；提交、传送和实际展示分开 |
| ENG-V07 迟到与部分失败 | 学生切换／暂停后评价返回；Belief成功但目标对照失败 | 不抢回旧活动、不重复更新，保留有效结果，只恢复仍适用的后续动作 |
| ENG-V08 上下文隔离 | 两空间相似题、摘要混入旧概率／错误引用、上下文超预算 | 解释不借用跨空间记录及后验概率；必需事实不静默裁剪，缺依据明确未完成 |

实现后建议测试放到`src/deermind/backend/tests/`，保存输入、断言、事务快照和运行配置；具体文件和命令在首批实现确定。事务／并发用真实数据库，不用仅内存仓储冒充。开发fixture不充当独立语义质量样本。

**停止条件。** 出现重复业务效果、错序更新、越权取材或检测轮内泄露提示，停止依赖该机制的接线，修订方案或重开TECH-03比较。上述通过不证明整册识别、概率校准、学习效果或部署容量达标；这些按validation另验。

## 5. 工程测试与质量验证衔接

待设计：按确定性纯函数、接线集成、浏览器交互、语义质量四层安排检查，明确被测模块、输入、参考结果与证据位置；开发案例与独立评测分开。数值核心覆盖参数非法、阈值边界、跳过、同方法跨参数更新、四方面有效L及教学预测不独自达标；接线覆盖机会／Evidence去重、顺序、并发、恢复和分层失败，不能用浏览器mock数字代替算法测试。

预期产出：测试责任和证据位置表，对照[验证计划§1](../../../m1/validation/Validation_Plan.md#1-验证什么由什么证据回答)的五类对象：教材解析纠错、领域补建采用、Evidence资格与帮助判断、概率计算与事件更新、概率预测与学习效果。对象类别与测试层次不是一一对应；前四类落实到适用工程检查，预测校准和学习效果继续由validation安排，不能由纯函数或浏览器通过替代，不复制指标。
