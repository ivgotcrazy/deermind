**职责。** 定义各类AI任务如何获取必要且有资格使用的信息，如何保持历史连续性、来源及空间隔离。

**输入。** [AI Native 架构原则 v0.6 §4、§6](../../../top/DeerMind_AI_Native_Architecture_Principles_v0.6.md)、[内容规格 v0.22](../design/Content_and_Model_Reference.md)、[交互规格 v0.21](../design/Interaction_Design.md)；共同设计输入为[运行框架](Agent_Runtime_Design.md)和[业务运行机制](Business_Flow_Design.md)。

**预期输出与接收者。** 上下文合同、记忆归属与读写规则、检索及摘要机制、刷新策略和验证案例；供Agent执行、业务取材和数据接口实现使用。

**边界。** 不建立绕过各Space所有权的通用学生画像或第二套Belief；摘要不是学生表现证据，执行检查点不是长期能力判断。

下列章节只约定需要回答的问题与交付形态，尚未形成设计正文。互引的工程文档也处于大纲阶段，是交叉完善的分工，不是已经成立的输入合同。共同范围、唯一维护位置和推进顺序见[工程入口](README.md)。

## 1. 记录、状态、摘要与执行进度

待设计：分别规定原始事实、当前业务状态、历史摘要／索引和执行进度的来源、维护者、作用及失效边界。

预期产出：信息归属与读写表；存储结构由[数据与接口](Data_and_Interface_Design.md)维护。

## 2. 各类任务的上下文合同

待设计：分别列出教材助手、学习助手和证据解释任务的必需、可选、禁止和缺失信息，区分事实、请求、规则与派生判断。

预期产出：三类上下文包样例与资格规则；覆盖防止既有Belief诱导本次证据解释。

## 3. 活动森林中的连续性

待设计：说明父子活动交接、返回、活动摘要、未解决问题和历史引用；教材浏览不自动限定聊天或成为所问题目。

预期产出：上下文传递图、活动摘要要求与原始记录回查方式。

## 4. 检索、长度预算与多模态内容

待设计：说明按对象／活动／时间检索及语义召回候选、排序、上下文压缩和按需扩展，保留公式、表格与图形的必要信息。

预期产出：检索及组装流程、取材优先级和不足处理；向量检索是否需要及实现待论证。

## 5. 摘要生成与信息时效

待设计：说明摘要何时生成、覆盖哪些事件、怎样保留出处、补入未摘要的新消息，以及识别遗漏、过时或冲突。

预期产出：摘要生命周期、来源和有效性检查要求；原事实不随摘要替换而改写。

## 6. 并发与暂停恢复的刷新

待设计：区分待评价作答的当时条件与继续教学的当前状态，明确恢复时哪些信息固定、哪些重新读取和复核。

预期产出：刷新与重查表；对照[运行框架](Agent_Runtime_Design.md)的等待恢复协议。

## 7. 隔离、调用留痕与效果验证

待设计：定义空间及任务范围的访问限制、外部材料与指令区分、实际输入追溯，以及连续性、检索和证据解释验证场景。

预期产出：上下文质量检查项与案例；不提前建设自动记忆优化或Evolution平台。
