# E04-16 四分之一学习主线回归

2026-11-23 在既有 `deermind-m1` K3s 验证。应用 Helm 修订 81，API、Worker 和客户端均运行 `e04-16-r2`，数据库迁移为 `0037_interaction_memory`。

| 验证 | 实际结果 |
| :--- | :--- |
| 三种学习情境 | 基础不足、会做但解释不足、具备基础各走通讲解、追问、返回、确认题单、开轮及求助。每个场景均有浏览器截图、录像和数据库事件序号。 |
| 刷新与争用 | 刷新只读恢复原空间和原轮次，没有再次登记进入。求助受理后紧接着提交作答，后到请求收到 `interaction_busy`。 |
| 帮助事实 | 三例均先收束讲解，再开轮。求助顺序为闭轮、记录求助、正式提供帮助。先交卷再求助保留原回执、作答及已关闭的轮次。 |
| 反馈故障 | 单题合成课程使用既有题，提交后临时切断 Worker 到模型服务的连接。原作答保持已保存，反馈明确失败。恢复连接后重试原执行，同一恢复请求重放返回原受理，数据库保留一次提交和两次执行。 |
| 正误反馈 | 只提交正确数值判为部分正确，完整列式和解释判为正确。错答、重复提交和多轮续接见 E04-12。判断属于当前题反馈，页面无虚构掌握结论。 |
