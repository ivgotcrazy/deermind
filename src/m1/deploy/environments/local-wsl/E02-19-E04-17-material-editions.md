## 2. 五项验证结果

管理端普通入口复验：从 `/admin/` 登录，点击「教材管理」，搜索并打开第 49–50 页样本。在 1029 × 543 浏览器中，首屏同时看到教材原页、内容树、教学提炼。切换到「候选与领域入库」或「教材原件」，再返回列表点「查看教材」，默认再次打开工作台。[普通入口首屏](evidence/material-editions/admin-book-entry.png)

| 增量 | 实际结果 |
| :--- | :--- |
| E02-19 原页与内容树 | 真实教材第 49、50 页经 DeepSeek 解析出 29 个节点。第 50 页能反查普通正文和跨页题；第二种解法指向第 50 页，父题保留两页来源。 |
| E02-20 内容树工作区 | 在 v1 上建草稿，通过助手修正并核对三处节点变化。保存、重开、发布为树 v2 后仍有 29 个节点，v1 保留原内容。树 v2 发布时没有自动生成提炼。 |
| E02-21 教学提炼工作区 | 在树 v2 上主动重新提炼，取得绑定该树的新草稿。缺少可用领域方法的章节保留待处理原因，发布被阻止；补齐任务及方法后可发布。另用五页测试教材走完自动生成流程，树共 37 个节点，五节均产生任务与方法关联，合计 15 个原文节点引用，成功发布。 |
| E03-11 目标选版 | 「验收目标甲」和「验收目标乙」各自保存，并选用同一已发布提炼。提炼使用情况列出两个目标。发布后续提炼，重开目标甲和其学习空间仍读取原树与提炼；在目标表单可预览章节与任务，选项中没有草稿。 |
| E04-17 学生教材 | 两个独立浏览器会话分别登录管理员和学生。学生能从章节进入已过滤的学习地图，打开前置任务再返回，定位到与后台相同的教材原页。切换浏览位置时当前聊天活动保持原状。 |

## 3. 环境及保护检查

- 现有 K3s 的 API 和 Worker 使用 `deermind/server:book-editions-r7`，客户端使用 `deermind/client:book-editions-r6`。三个部署均已就绪，数据库迁移为 `0043_material_editions`。
- 集群 API 已核对草稿丢弃、过期修订拒绝、重复提交沿用原收据、不同教材之间的版本读取隔离，以及 Product 投影收据。生成的 OpenAPI 和 TypeScript 声明再次生成后摘要一致。
- 后端单元测试 107 项通过，Python 静态类型检查通过，Vue 类型检查及生产构建通过。真实浏览器脚本、用到的对象编号分别见[浏览器复验](../../../tests/browser/materials/edition-navigation.cjs)和[样本清单](evidence/material-editions/review.json)。在项目根目录配置测试账号环境变量 `M1_ADMIN_LOGIN`、`M1_ADMIN_PASSWORD`、`M1_STUDENT_LOGIN`、`M1_STUDENT_PASSWORD`，指定 `M1_TEST_EDITION_SCREENSHOTS` 输出目录后运行 `node src/m1/tests/browser/materials/edition-navigation.cjs`。使用自带 Chromium 或以 `M1_TEST_BROWSER_EXECUTABLE` 指定浏览器。
- 调整前本机有 12 本测试教材，其中「E04 合成教材 · 增加四分之一」被 27 个目标和 33 个空间引用。其余是三本整章浏览器样本、四本 C02/C03/C05/C06 样本、两本教材交互样本、「接收与原页」和「整章核对 · 匀速运动」。旧空间沿用原采用记录；需要使用新学习地图时，由管理员重新解析教材、发布提炼并创建采用该版本的目标和空间。
- 第 49–50 页用于验证真实教材上的跨页定位与修正；五页整本为合成样本，使用已登记的领域任务。测试空间中的父任务和前置关系用于验证导航。整册扫描教材的提炼质量、成本和耗时尚需按实际教材测量。
