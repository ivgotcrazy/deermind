# 教材、领域模型、评估标准和课程目标验收

> v0.5 · 2026-11-28 · local-wsl / K3s · 待用户统一评审

## 1. 从哪里看

在[管理后台](http://127.0.0.1:5184/admin/)进入「教材管理」，搜索 **分数的应用 · 模型验收**。详情默认显示教材原件，另外三个页签为内容树、教学提炼、工作台。在工作台选择已发布的内容树 v1 和教学提炼 v2，即可对照北师大数学书页 49、内容节点及教学任务。[工作台截图](evidence/book-models/admin-book.png)

从「评估管理」选择领域 **数学 · 教材建模验收 14307d**、同一本教材和教学提炼 v2，可查看已发布的「课堂标准 3」「课堂标准 4」。进入「目标管理」打开「独立完成分率计算」，对照它选用的套和 Claim。同领域的「分数的应用 · 同名隔离验收」保有一套评估草稿，可查看草稿编辑及删除拦截。[领域视图](evidence/book-models/admin-domain.png) · [评估套列表](evidence/book-models/admin-assessment-list.png) · [评估判据](evidence/book-models/admin-assessment.png) · [目标选版](evidence/book-models/admin-goal.png)

用测试学生进入[学习空间](http://127.0.0.1:5184/student/)，打开教材。章节显示目录，学习地图按章节筛选任务，原始教材显示书页。选择书页或任务时，当前聊天活动保持原状。[章节](evidence/book-models/student-chapters.png) · [地图](evidence/book-models/student-map.png) · [原页](evidence/book-models/student-original.png)

## 2. 在集群上实际执行的操作

| 增量 | 操作及结果 |
| :--- | :--- |
| E02-19 | 创建空教材即阻止删除领域。原件可在没有树时删除、重导；有树草稿则拒绝删除原件。正在使用的教材删除被拒，临时空教材及其空领域可依次删除。 |
| E02-20 | 从原图生成树，人工保存并发布。复制发布树，在浏览器内新增同级和子节点、修改正文，取消后再确认删除整棵分支，重新读取核对。过期修订不能覆盖已保存的编辑；原发布版保留原文。分别在 1029 和 1560 像素宽的管理界面检查三列。 |
| E02-21 | 同一领域的两册教材分别从原件生成内容树、提炼草稿。手工设置同名任务并发布后，任务、方法、KC 分别取得独立身份。跨教材读取他书版本被拒。在浏览器复制发布提炼并手工改写任务，重开草稿仍可读回修改；复制版另行发布时获得新身份，其评估标准列表为空，原模型仍可读取。 |
| E03-11 | 对同一提炼真实生成两套评估草稿，手工修订、分别发布，产生独立 Claim。选套内 Claim 可保存目标，混入另一套返回 409。另一本教材只有一套评估草稿、尚无目标，删除提炼同样返回 409 并指出标准名称。缺少任务判据的草稿不能发布；校验后恢复了草稿内容。 |
| E04-17 | 发布课程，学生用固定目标进入空间。从章节切换到过滤后的地图，打开任务，再到原页引用原文。目录中没有题干等正文节点；切换时当前聊天活动保持不变。 |

## 3. 复验条件与范围

- Helm 应用 revision 155。API 与 Worker 镜像 `deermind/server:book-models-r5`，客户端 `deermind/client:book-models-r6`，业务库修订 `0045_edition_owned_members`。沿用现有单节点 K3s。
- 后端 110 项单元测试通过。Python 与 Vue 类型检查、Ruff、变更客户端的 ESLint、后端模块依赖检查及前端生产构建通过。OpenAPI 和 TypeScript 声明由同一份后端定义导出。构建器提示管理端主脚本约 525 kB，gzip 后约 173 kB。
- 浏览器脚本使用复核样本清单。设置合成账号的 `M1_ADMIN_LOGIN`、`M1_ADMIN_PASSWORD`、`M1_STUDENT_LOGIN`、`M1_STUDENT_PASSWORD`，在项目根目录用 Node 运行脚本。默认服务地址为 `http://127.0.0.1:5184`，可用 `M1_TEST_BROWSER_EXECUTABLE` 指定浏览器。[浏览与选版](../../../tests/browser/materials/edition-navigation.cjs) · [直接引用和草稿隔离](../../../tests/browser/materials/edition-references.cjs) · [样本编号](evidence/book-models/review.json)
- 本轮以同一张真实数学样页建两册测试教材，验证版本隔离和两端流程。整册提炼的准确率、耗时与费用未测。上一轮第 49–50 页跨页样本的截图保存在[历史证据目录](evidence/material-editions/)。
