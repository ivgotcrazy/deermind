# E04-03 学生输入与停止

2026-11-23 在现有 `deermind-m1` K3s 验证，待评审。应用 Helm 修订 58，API、Worker 和客户端就绪。

| 场景 | 验证结果 |
| :--- | :--- |
| 正式受理和丢失回执 | 在合成课程中发送消息。代理先让 API 保存，再丢弃 HTTP 应答。浏览器用原请求编号取得回执，正式聊天只有一条学生消息，Temporal 与 DeepSeek 生成的完整回复正常显示。 |
| 空间忙、重复提交与停止 | PostgreSQL 上验证忙时拒绝新的消息、原请求返回同一工作、停止后补读为已停止、原学生消息仍保留。 |
| 浏览器草稿 | 固定响应验证忙时可继续输入，停止后保留下一条草稿。 |
| 工程检查 | Pyright、Vue 类型、依赖检查与 71 项后端单元测试通过。K3s PostgreSQL 回归 12 项通过。 |

学生端固定以 HTTP 发送，连接恢复后刷新正式消息，受理不明时沿原请求编号查询或重试。学生模型配置独立于教材助手，本机共用已配置的 DeepSeek 服务凭据。

验收证据位于 `src/m1/.artifacts/e04-03-k3s-20261123/`。验收课程通过现有教材和课程接口建立，使用合成材料和合成学生。活动分类、自由交谈归属和澄清走查归 E04-04。
