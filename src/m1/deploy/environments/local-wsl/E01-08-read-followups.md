## 现行读取合同

| 路径 | 调用方决定 | Foundation 执行 |
| :--- | :--- | :--- |
| 指定事实 | Product 核对会话和收据归属，点名条件与确认记录 | read_facts 按账号、事件 ID、预期类型和版本、原请求关联号匹配，再读取指定片段 |
| 账号重建 | 维护入口核验身份和任务。账号投影器维护采用的类型 | scan_scope 沿用维护连接逐号核对固定范围。生成与复核各自扫描，只返回通过格式、业务不变量及附件校验的目标事件 |
| 元数据列表 | 业务入口限定范围、筛选和对外可见字段 | query_metadata 返回源事件元数据、固定上界及下一页起点，不展开正文 |

[公共运行设计 §2](../../../../../doc/mvp/m1/engineering/System_Foundation_Design.md#2-全局事件的追加与查询)维护读取规则，[Product §2.8](../../../../../doc/mvp/m1/engineering/Product_Application_Design.md#28-账号业务投影与维护重建)维护账号重建规则。原有写入授权、正式事件和数据库结构保持原合同。
