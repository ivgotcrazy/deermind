## 1. 交付

基线`f2bb5e7`，验证批次`e01-15-20261116`。本轮实现模型底座，不接正式教材、教学或评价。

- 受理时固定模型、用途、工具许可和预算。密钥在外发前读取；恢复保留原配置及累计用量，不自动换模型。
- 官方Pydantic AI Temporal集成分别保存模型和工具步骤。工具采用FunctionToolset；不让自定义工具在Workflow中执行I/O。
- 每次传输先登记、后调用；失败和格式修正计次。供应商未返回用量时保留预约并标未知，不能算零。
- 工具通过用途许可、调用方授予、当前业务权限三重检查。重复动作复用已存结果，写草稿工具使用所有者防重键。
- 候选按登记Schema验证、固定为附件，与调用完成事实共同保存。保存失败整体回滚；已保存候选直接复用，停止后拒绝迟到提交。

固定依赖为Pydantic AI Slim 2.68.0（openai、temporal扩展）、OpenAI SDK 3.51.0；Pydantic与Temporal SDK未升级。`0011_ai_calls`接线七张既定表，字段及约束由[AI数据字典](../../../../../doc/mvp/m1/engineering/database/Business_AI.md)维护。

## 2. 实现位置

| 位置（相对server/src/deermind） | 职责 |
| :--- | :--- |
| `foundation/ai/contracts.py`、`records.py` | 固定配置、调用输入、预算及完整事实正文 |
| `foundation/ai/execution.py`、`store.py` | 受理、累计记账、未知结果、候选和失败收尾 |
| `foundation/ai/tools.py` | 工具登记、当前授权、参数检查及结果收据 |
| `foundation/ai/facts.py`、`projections.py` | AI自己的事件合同及投影转换，公共事件底座不转换AI数据 |
| `infrastructure/ai/` | 模型协议、官方Temporal集成、工具Activity及候选保存步骤 |
| `foundation/system/events/attachments.py` | 复用固定JSON附件保存、hash校验和同源读取 |

工作内输入以固定调用键防重；恢复增加AI尝试，上一尝试未确认的请求保留预约。旧尝试没有结束结果时明确记为unknown。模型及文件I/O不占业务事务；事务只保存事实、投影和计数。

## 3. 验证

证据保存于M1根目录`.artifacts/e01-15-20261116/`。97项验证通过：本地53、AI专项5、真实模型1、执行恢复11、文件14、迁移8、部署5；重复运行不重复计数。集群AI组另有1项真实模型用例默认跳过，该项已在显式真实测试中验证。真实测试累计外发1次，输入292、输出52 tokens；返回可校验候选，再次执行直接复用。无价格依据，费用记未知。合成问题及结果在`live-result.json`，累计次数在`live-request-ledger.jsonl`；账本不可删除或重置。

本轮批准最多6次外发，每次输入4096／输出512 tokens，全批27648 tokens；每项工作300秒，预留10秒，格式最多修正一次。输入按UTF-8字节数加框架余量保守估算，供应商实际用量另记。故障、越权、格式修正使用本地替身，不消耗真实额度。

| 检查 | 验收点 | 证据 |
| :--- | :--- | :--- |

## 4. 自查与边界

已逐文件检查调用身份、预算扣减、原子保存、工具权限、错误脱敏及代码分段。缓存响应执行与新响应相同的工具校验；未知外部结果不伪装成功；无新的通用Agent框架或业务规则。
