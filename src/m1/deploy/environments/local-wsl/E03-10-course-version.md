# E03-10 课程发布与固定空间

2026-11-24，部署到现有 `deermind-m1`。Helm 修订 101，API 与 Worker 使用 `course-version-r2`，客户端使用 `course-version-r3`。数据库迁移为 `0042_fixed_space_course`。

## 交付

- 管理员从「目标管理 → 检查与应用」检查并发布版本。每个空间固定选用时的课程及目标修订。
- 学生正常登录进入最近使用的空间，可在页内切换。新版课程创建新空间，重复选用同版复用原空间。
- 经用户确认，现有 3 个曾调整采用的试用空间固定在迁移时实际使用的版本。迁移前后 13 个空间的采用及历史序号逐条一致。

## 验证

| 场景 | 结果 |
| :--- | :--- |
| 数据库 | 12 项隔离 PostgreSQL 回归通过。覆盖有数据的迁移复验、旧版与新版分别计算目标、重复选用及初始评价防重 |
| 管理端浏览器 | 过期检查拒绝；发布课程 v2 时丢弃成功响应，查原收据恢复；重复确认相同内容沿用已发布版本 |
| 学生端浏览器 | 长列表可滚动。创建 v2 空间时丢弃成功响应，查原收据进入；同版重复选用返回同一空间；切回 v1 并从普通学生入口恢复 v1。旧空间采用和目标结果保持 |
| WebSocket 断线 | 主动断开真实连接，浏览器重新订阅原空间并补读会话，未重复提交进入请求 |
| 学生布局回归 | 在集群页面用固定会话夹具验证浏览章节、收起和展开、历史子活动定位、刷新恢复、发送补读和停止后保留草稿 |
| 静态检查 | 后端单元测试 102 项通过；Ruff、Pyright、客户端 ESLint、Vue 类型检查、OpenAPI 类型一致性及生产构建通过 |

浏览器输出、截图和空间版本对照见本机 `.artifacts/frontend-course-version-20261124/`。本轮验收范围为课程发布、空间选用和切换。
