# E02-18 教材到领域四例回归

## 1. 范围和判定

固定 C02、C03、C05、C06 的既有样页。对照原页核对候选，再按需经教材助手修正。教师提示、原题与原有参考分别保存。每例需留下原件、候选、采用、领域实例和章节关联的对应记录。2026-11-22 与 2026-11-23 的证据分别保存在 `.artifacts/e02-18-k3s-20261122/` 和 `.artifacts/e02-18-k3s-20261123/`。

## 2. 复核入口

- `tests/browser/materials/representative-extraction.cjs` 从浏览器运行首次解析及引用纠错。
- `tests/browser/materials/representative-intake.cjs` 前置人工核对，随后执行候选采用、领域归类、入库和章节采用。
- 真实模型调用只使用这四例及必要样页。后续合理测试用量由实施方直接安排并记录，DeepSeek 账户额度不足时再请用户介入。

### 3.1 首次结果与修正记录

- C02 首轮缺少跨页题面细节，后续纠正了约分。归类先后出现错误候选编号、依据与结论相互矛盾、引用越界。这些结果都未用于入库。提示词 v5 改为先给依据再给结论，父题与参考分别使用唯一的定义依据编号。原始凭证保留为 `prior-C02-check-*.json`、`C02-contradictory-*-receipt.json` 及 `C02-outside-definition-r7-receipt.json`。
- C06 先后遇到 JSON 未闭合、轮廓偏差和章节键遗漏。程序拒绝无效格式与无效章节引用。合法候选再通过对话修正图形、沿用章节和退役重复的 KC。`C06-before-correction-*` 和 `C06-invalid-chapter-*` 保留补测过程。

### 3.2 交付验证

- 最终部署 `e02-17-r8`，Helm revision 44，迁移 `0023_material_deletion`。API、Worker、浏览器客户端各 1 个就绪实例。
- 本地 67 项后端测试、8 项编程与架构检查、4 项部署目标测试通过。K3s 隔离库的 11 项领域数据库回归通过。
- 四例及恢复补验共记录 43 次真实模型请求，261,140 输入 tokens、77,509 输出 tokens。见 `model-usage-final.txt`。

端到端脚本记录各自处理时长。人工核对用时未单独计量。质量结论限于四个固定样例，整册按 E07 验收。
