# E04-06 答疑与讲解嵌套

2026-11-23 在 `deermind-m1` K3s 的真实学习空间复验，应用 Helm 修订 66。

| 场景 | 结果 |
| :--- | :--- |
| 插入答疑 | 从“四分之一”讲解进入子答疑，原讲解等待子活动。 |
| 答疑中插入讲解 | 从答疑进入“单位一”子讲解，按自身蓝图和规则运行。 |
| 返回主线 | 两次结束分别回到原答疑和原讲解，活动身份与返回节点一致。 |
| 查看历史 | 从活动目录定位已结束的子讲解，当前活动保持原讲解。 |
| 规则来源 | 候选引用错规则时，仅用实际生效的规则和本轮输入复核；程序复查后才采用。定点测试 9 项通过。 |
