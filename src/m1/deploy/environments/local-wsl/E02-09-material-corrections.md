# E02-09 教材助手对话修正

## 交付范围

- 从教材对话引用已有候选批次。工作固定旧候选和原页，生成可核对的新批次。
- 已存候选保留。新批次覆盖完整后，替代此前尚未采用的候选；仍缺材料时保留上一批。
- 同一教材同时间只受理一条消息。页面保留草稿和原请求编号，刷新后继续查询；处理完成后可再发送。

## 整章与定点修订复验

五页合成教材的第 4 页开始一道题，第 5 页接续小问并给出两种解法。通过已部署 API 上传，真实教材助手返回一章、三项知识成分、一道题和两种同父题解法，覆盖五个来源页。指定题目只改标题后，逐项比对其他五项正文均相同；整批采用后重新读取仍是六项。

可重复的浏览器用例为 [chapter-review.cjs](../../../tests/browser/materials/chapter-review.cjs)。它生成合成页图，调整顺序后通过“上传并解析”启动，核对来源与修订，再操作采用、领域接收和章节关联。设置 `M1_TEST_DOMAIN_ORIGIN`、`M1_TEST_DOMAIN_LOGIN`、`M1_TEST_DOMAIN_PASSWORD`、`M1_TEST_DOMAIN_BROWSER_EVIDENCE` 后运行。截图与 API 快照保存在本机 `src/m1/.artifacts/material-chapter-20261125/`。

local-wsl 的应用发布记录为 Helm revision 135。浏览器用例通过，复核教材名为“整章浏览器验收 cda7c3bd”。重新打开后能看到领域接收结果，820 像素宽的窗口无整页横向滚动。另用 C06 图题验证了图表原页预览、图表引用及纠错草稿刷新恢复。对已采用的一种解法连续修订两次再采用，父题引用和其余五项正文均保持原值。后端 104 个单元测试通过。
