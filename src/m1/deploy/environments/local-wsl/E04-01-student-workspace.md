# E04-01 学习空间单页

学习空间进入后默认展开聊天记录和教材，输入框始终可用。展开偏好保存在当前浏览器，按账号和空间隔离。收起或展开只改变布局，保留本次输入和阅读位置。聊天受理随 E04-03 接入。

在现有 `deermind-m1` K3s 部署客户端镜像 `e04-01-r1`，Helm 修订 56。浏览器使用实际合成学生账号，课程和两章正文使用固定夹具。核对了首次打开、切换和显示章节正文、隐藏／恢复时保留输入与阅读位置、再次进入恢复布局，以及阅读和折叠无写请求。

证据位于 `.artifacts/e04-01-k3s-20261123/`。部署见 `deploy.txt`，浏览器结果和截图见 `browser/study-layout.txt` 和 `browser/study-layout.png`。
