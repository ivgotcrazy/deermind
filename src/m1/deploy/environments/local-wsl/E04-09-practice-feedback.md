# E04-09 例题、练习与当题反馈

2026-11-23 在 `deermind-m1` K3s 验证，迁移 `0032_teaching_tasks`，应用 Helm 修订 71。

| 场景 | 结果 |
| :--- | :--- |
| 例题 | 在讲解中通过 Domain 取到已保存的题，聊天显示富内容题面，可展开对应解法。 |
| 练习 | 题目使用身份与例题分开。聊天显示题面及答题区，发送给浏览器的卡片没有参考解法。 |
| 提交错答 | 以 `0` 提交，收到正式回执及真实模型反馈。数据库确认 `AnswerSubmitted`、`round_id=NULL` 和 `incorrect`，答题原文没有复制成聊天消息。 |
| 无合格库存 | 复验中耗尽已接触范围外的题，实时生成的候选未通过复核时，聊天明确返回缺口。补充已检查的合成库存后重跑完整主链。 |
