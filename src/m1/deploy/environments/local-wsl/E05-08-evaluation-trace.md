# E05-08 管理员评价追溯

在现有学习空间的“学习目标”查看 Evidence 列表，在证据详情看评价说明、概率变化及来源事实。在“空间事件”从作答反查本次形成的证据。

使用 Playwright 在 `deermind-m1` 完成真实浏览器复验。目标显示可追溯的正证，打开原始作答可见实际列式。另一个已存在学习空间的同一 Evidence 引用返回 404。原文按已登记片段读取，查询过程不会重新评价。

浏览器脚本为 `tests/browser/evaluation/evidence-trace.cjs`。日志和两张截图位于 `.artifacts/e05-10-k3s-20261123/browser/`。
