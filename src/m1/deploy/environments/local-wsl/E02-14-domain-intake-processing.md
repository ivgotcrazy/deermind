# E02-14 领域待入库处理

## 1. 交付范围

领域管理员可按待办添加或复用 KC、关联已核对题目、补入原有参考解法，或移除待办。题内参考追加父题实例版本。补入 Task 尚未采用的方法还需管理员明确确认。
