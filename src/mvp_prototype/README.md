## 当前入口：三端结构低保真稿

本轮学生默认进入“首页”，主导航为“首页／学习情况／教材／学习记录”。首页回答最近在学什么、下一步做什么，以及近期开展了哪些活动；学习情况直接进入可搜索、可筛选的章节目录，再看单章表现与依据。具体学习仍在连续对话工作区开展。家长使用“概况／咨询”，后台使用六个稳定工作区；本次没有重做其他角色。它用于审阅内容和操作过程，不是最终视觉稿。内容口径见 [Requirements §3.11](../../doc/mvp/phase-3-definition/MVP_Requirements_and_Acceptance.md#311-首页内容与活动统计)，页面分工见[交互设计 §2.3](../../doc/mvp/phase-4-product-and-domain-foundation/MVP_Product_and_Interaction_Design.md#23-学生端首页学习情况与连续活动)。

在仓库根目录运行：

```powershell

.\prototype.cmd start -Structure -Role parent
.\prototype.cmd start -Structure -Role admin
```

入口：[学生端](http://127.0.0.1:5178/structure.html?role=student)、[家长端](http://127.0.0.1:5178/structure.html?role=parent)、[管理端](http://127.0.0.1:5178/structure.html?role=admin)。原 `phase4.html` 顶部也有“新版结构走查”链接。`-Structure` 与 `-Foundation` 二选一，沿用相同服务、端口及停止命令；服务已运行时只打开入口，源代码变化后应重建或停止再启动。本次已构建供当前服务读取。

### 课堂进度：学生确认，家长只读

打开[学生首页](http://127.0.0.1:5178/structure.html?role=student#/home)，课程名称下方突出显示“学校正在学”和章节；未填写时显示“学校现在学到哪里？”。点击“设置进度／更新进度”，选择学校正在学的章节，必要时补充小节说明。[学习情况](http://127.0.0.1:5178/structure.html?role=student#/status)保留轻量入口，两处更新使用同一记录，章节旁同步显示“课堂正在学”；不会更改掌握情况、产生学习活动，或将之前章节自动记为已学。首次保持“尚未填写”，也可以主动保存“暂不确定”并清除当前标记；刷新可恢复。取消或 Escape 放弃本次编辑。

首页显示上次确认日期；详细时间、来源和更新历史放在弹窗内，家长在同一孩子和课程下只读查看。长目录支持搜索和分页。当前记录保存在本浏览器，绑定原型教材版本；自然语言理解后提出候选、初次创建空间时询问及正式建议使用尚未接入。产品规则见 [Requirements §3.12](../../doc/mvp/phase-3-definition/MVP_Requirements_and_Acceptance.md#312-课堂进度与学习状态的区分)，实现见 [ClassroomProgress.vue](src/structure/ClassroomProgress.vue)，检查见 [structure-classroom-progress.spec.ts](tests/structure-classroom-progress.spec.ts)。

**本轮检查（2026-10-17，首页入口修订）。** 类型检查、生产构建及最终 24 项课堂进度／首页／统计检查通过（37.5 秒），覆盖首页与学习情况相互更新、刷新、未知、课程隔离和家长只读。初轮发现横向短屏的主要学习按钮被挤出首屏，调整为宽屏下课堂进度与学习操作并排，窄屏按课堂进度、学习操作、近期摘要排列，复验通过。已查看 1280×900、834×1112、390×844、1024×600 的截图：课堂信息与更新按钮醒目可见，主要学习动作仍在首屏，没有横向溢出或正文与输入区重叠。截图及几何检查见[本地复审目录](../../.tmp/classroom-home-review/)，最终文件以 `final-` 开头。前轮更新弹窗、目录及 300 章走查保留于[课堂进度检查目录](../../.tmp/classroom-progress-review/)。本轮为隔离浏览器中的作者检查，没有改变用户已有记录或调用真实模型，不代表 Android 设备或正式权限验证。

### 真实模型对话：现在可以使用

在[分数的应用](http://127.0.0.1:5178/structure.html?role=student#/chapter?chapter=fractions)点击 **开始章节讲解**，或从学生首页开始学习，直接进入真实对话，不再选择另一个“真实对话”入口。整个活动页面由简短标题、对话正文和常驻输入区组成；讲解、图示、题目、作答和反馈都在这里完成。课程导航退回首页后再显示。

普通入口继续旧的分数讲解时，会自动接到新的对话活动，并记住对应关系；旧活动及草稿保留，只复制未发送草稿，不自动发送，不将预写教学或示例学生表现放进模型上下文。旧的进行中检查仍按原规则完成或结束，不因页面更新强制退出。其他章节暂不开放真实教学，预写情境从顶部走查工具进入。

- **真实处理范围：** 分数应用及必要基础回补；模型生成讲解、简单公式、同刻度条形图、练习、即时单题检查及本次反馈。输入只含本次真实交流和作者内容参考，不读预写个人状态或其他课程记录。
- **检查边界：** 点击开始后收起前文，题目仍是一条对话内容，底部输入区继续承接答案与理由；提交即结束该题，再反馈。求助先结束检查，再讲解，未作答不记为错误。结束过的检查不能重新开启；继续交流可另开新题。
- **连续性：** 原地址内完成交流与作答。“稍后继续”保留活动，“这次先到这里”暂停，之后可继续。每个会话只处理一轮，等待时可停止；网络失败保留输入，由用户重试。未知送达状态使用同一请求编号确认，避免双击重复调用。
- **保存位置：** 实际输入、回复、题目、原作答及调用时间与用量保存在仓库 `.tmp/mvp-live/`，不进入 Git；草稿及活动入口保存在当前浏览器。重启服务、重新构建不会删除记录。服务异常中断后提示重试，不自动重发。
- **限制：** 当前只接受文字，公式用可读的 `a/b` 和数学符号，没有 OCR、手写、语音或逐字流式显示。模型返回完整一轮后展示；内容使用限定组件，不执行任意 HTML。反馈不创建正式 Observation／Evidence／Belief，不更新章节掌握状态。家长和后台尚未接通这条真实对话的完整追溯。

后台沿用根目录 `.env` 的 `DEERMIND_LLM_API_KEY`、`DEERMIND_LLM_BASE_URL`、`DEERMIND_LLM_MODEL`，当前为 DeepSeek 官方服务及 `deepseek-flash`，非思考模式。密钥不传给浏览器。接口仅开放给本机同源页面；`-Lan` 仍供预写界面走查。这是成人本机体验环境，没有正式账号授权，不据此开展真实儿童数据试用。更改配置后运行 `prototype.cmd stop`，再运行 `prototype.cmd start -Structure`。

一次输入上限 12000 字符，会话上限 160 条记录，模型上下文上限 180000 字符；达到边界提示另开活动，不静默裁掉历史。一次操作最多两次模型调用（初次及一次格式修复），共同等待上限 90 秒。用户重试会再次调用；失败和停止的调用也可能产生供应商费用。

实现见 [LiveLesson.vue](src/structure/LiveLesson.vue)、[live-api.mjs](scripts/live-api.mjs)、[live-service.mjs](scripts/live-service.mjs)、[live-model.mjs](scripts/live-model.mjs)。内容只取作者候选包的知识、问题与解法定义，不将其视为已发布 Domain，不复用已关闭的 Spike／Build 账本。

**本轮验证。** 后台 7 项确定性检查、25 项浏览器检查及类型检查／构建通过。首轮真实模型 6 轮走通，单轮 1.8–2.8 秒，合计 19428 tokens；只是局部样本，不是延迟承诺或教学质量通过。输出暴露了不支持的画图作答要求及学生表现误归属，已收紧提示，限定文字作答、要求个人表现描述对应真实输入。结构校验不保证语义正确，尚未执行独立语义评测。最终复验与截图见[本地结果](../../.tmp/mvp-live-check/result.json)及同目录；检查使用隔离浏览器，不改用户已有记录。

修正后再次完整走通 6 轮，模型耗时 1.5–4.3 秒，合计 20219 tokens，没有格式修复或传输失败；该次未再要求画图作答，也未把教师刚讲的规则当作学生已表现。实际检查了桌面、窄屏截图及检查草稿恢复。随后后台 7 项、真实模式 3 项浏览器检查通过，包含从学习记录返回原对话。两轮共 12 次真实调用，不据此推断一般准确率；原始首轮结果保留为同目录 `first-run.json`。

### 预写情境：保留对照与回归

此前的预写连续对话仍可操作：从顶部“预写走查”打开[对照入口](http://127.0.0.1:5178/structure.html?role=student&preview=scripted#/chapter?chapter=fractions)，再点击“开始章节讲解”。该标记只用于评审，不是学生需要选择的教学模式。讲解、图示、练习、检查安排与结果仍在同一个活动地址内展开。

1. 展开活动内的“教学情境”，选择“理解较快”或“基础回补”预写路径。每次活动选择一条，另一条另开活动查看，不覆盖已有输入。
2. 自由输入直接出现在当前对话，按原顺序保存；原型不会理解输入或用预写回应冒充真实回答。示例学生表达单独标注，不写成个人作答。
3. “一起练一练”展开可填写的练习卡片；“检查一下这次理解”在原位置展开安排，确认后出现检测题。练习与检测提交分开保存，均保持尚未判定；家长记录和后台案例可只读实际提交。
4. 检测中收起此前教学与对话，求助先结束检查，再显示预写帮助；结束后的检查不能重开。检测时底部自由输入只保存补充说明，不替代题目内作答，也不会自动提供解题帮助。
5. 刷新恢复内容和草稿，回看前文时新消息不强拉到底部。旧会话自动保留已有段落、作答和消息，新活动使用连续对话。当前“圆”“比的认识”也采用内嵌检查，但只保留原有预写教学，没有两条分支情境。

上述预写情境的卡片由本地 Vue／HTML／CSS 组件呈现；真实模式也使用限定组件，由模型生成结构化内容。预写模式未实现语义理解或评分；两种模式均未接真实语音、手写及长对话分段折叠。主要教学操作直接内嵌。可另从[学生首页](http://127.0.0.1:5178/structure.html?role=student#/home)检查下面的进入情境。无路径入口和 `/home` 进入首页，`/status` 进入章节学习情况；旧 `/home?chapter=…` 保留章节访问，原有记录与草稿继续保留；进行中的检测仍先按原规则处理。

- 有未完成活动时显示上次停在哪里，按最近实际使用的活动继续；结束后显示最近一次结果，并区分阅读、提交和评价。
- 没有当前活动时展示一项有可查参考的预写建议，可以暂不安排；教材仍可自主选择。展开“为什么建议这个？”可见题目、参考作答、当时帮助及推断限制。
- 首页只聚焦一个最近主题；学习情况负责完整章节查询及单章详情。目录支持名称／路径搜索、分册／单元／状态筛选，每页至多 12 章；详情返回保留筛选、页码、位置和焦点。从首页打开的章节可返回首页。默认 3 章未覆盖全册，13 项参考要求按需展开；新的学习要求方案仍是讨论稿。无评价时不显示负面结论，无可比记录时不生成进步或正确率。
- 首页“学习足迹”按独立预写事件计算：截止 2026-10-17，近 7 天为学习 4 天、讲解 3 次、已结束检测 2 次；近 30 天为 5 天、4 次、2 次。当前错题按不同题目去重为 6 题，不随时段改变，也不是“尚不会”的题数。点击数字能核对对应明细，示例没有接到另一组千条合成历史。本轮真实对话保留在实际活动中，未纳入这些示例；无可用参考时显示尚未统计，不编造 0。
- 底部可直接输入文字或带入一张图片，发送后在正文看到已保存内容，不自动展开历史。图片仅在本浏览器保存，支持 JPEG／PNG／WebP、单张不超过 2 MB；没有识别或解题处理。正文和输入区分别占位。

顶部“首页情境”属于评审工具，可切换已有评价参考、尚无评价、首次学习参考、今日 26／30 分钟及 3／30／300 章目录情境。新增章节是合成占位，含重名和长名称，无教学内容或评价，不代表实际教材及模型覆盖。切换不删除已有活动；下一步区域优先呈现最近活动，首页主题与学习情况目录分别保留。“首次学习”只覆盖已选课程、尚无历史参考的情形，不表示创建空间流程已经完成。时间是明确标注的示例，实际计时未接入；达到示例上限时提示收束，不强制锁屏。HOME-REF-01 是预写依据，不是真实模型判断。

也可完整走一条跨角色过程：

1. 学生从教材选择任意一个章节，逐段阅读，参加结束检查并提交自己的文字作答。
2. 切换家长端，在“本轮实际学习记录”找到刚才的提交，查看原作答及帮助，再明确提交复核说明。
3. 切换管理员，在工作台进入该事项，填写本次查看用途，分别查看交互、评价、版本和处理记录；保存人工意见后，家长可在原事项查看。
4. 另从后台账号目录搜索 `S0701`，或按学生筛选并翻页，进入档案及案例后返回，核对查询条件保持。学生的学习记录也支持筛选、分页和原位置返回。

**已经落实的部分：** 三个可替换章节、分段继续与暂离、检查求助先结束、实际作答跨端只读、复核与人工意见、常驻输入和按需历史、按孩子／空间／活动保存草稿、目录查找及详情返回。任意输入只保存并说明尚未理解或执行，不使用关键词模拟语义理解。

**数据与边界：** 合成目录有 1,000 名学生、1,500 名家长、20 本教材、5,000 个模型对象版本条目、10,000 条活动索引和 200 条任务；参考学生的校内空间生成 1,000 条记录，活动视图取其中 200 条。本家长可切换两名合成孩子，校外空间保持无内容状态。目录条目不表示已有完整对象定义或真实关联，章节状态与历史判定是预写参考，不随本轮实际提交变化。这是信息组织材料，不能据此声称已通过千人性能验证。

## 一键启动

电脑需要 Node.js 22.12+（也支持 20.19+ 的 20.x）；首次运行需要联网安装锁定依赖。**在仓库根目录双击 `prototype.cmd`**，脚本会安装依赖、检查类型、构建、启动隐藏的本地预览服务并打开学生首页。它与 Build 验证工程的 `deermind.cmd` 分开。

也可在仓库根目录使用以下命令，无需手动进入前端目录：

```powershell
.\prototype.cmd start
.\prototype.cmd start -Role parent
.\prototype.cmd start -Role admin
.\prototype.cmd status
.\prototype.cmd stop
```

默认地址：

| 入口 | 本机地址 |
| --- | --- |
| 学生端 | http://127.0.0.1:5178/#/student/home |
| 家长端 | http://127.0.0.1:5178/#/parent/overview |
| 管理端 | http://127.0.0.1:5178/#/admin/dashboard |

页面顶部也能切换角色。该工具栏属于原型走查工具，正式 App 不用它切换身份。后台进程会继续运行；关闭浏览器不停止服务，使用 `stop` 停止。

平板或手机与电脑连接同一可信局域网时，可运行：

```powershell
.\prototype.cmd stop
.\prototype.cmd start -Lan
```

脚本会输出电脑的局域网地址，在设备浏览器打开相应地址即可。设备必须能访问电脑的端口，Windows 防火墙可能需要允许此连接。默认只监听本机；`-Lan` 才监听局域网。可用 `-Port 5188` 更换端口，后续 `status`、`stop` 使用相同参数；`-NoBrowser` 不自动打开浏览器；`setup` 仅安装和构建。

已运行时重复 `start` 会复用原服务。修改源码后先 `stop` 再 `start`，重新构建并刷新浏览器。日志和进程标识保存在仓库 `.tmp/mvp-prototype-<端口>*`，停止操作会校对进程身份，不按端口任意结束其他服务。

## 旧原型的四条流程（含已退出范围的整卷样例）

1. **试卷到讲解**：学生首页 → 拍题/上传 → 使用示例试卷 → 确认错题 → 八折题 → 只给提示 → 完整讲解。可在文字区输入或用鼠标、触控笔在笔迹区书写；原作答与新练习分别显示。
2. **自测中途求助**：学习情况 → 从教材选择自测 → 选“百分数的应用” → 提交第一题 → 第二题请求讲解。确认后结束自测，已提交作答和草稿保留；返回检测结果，未做题仍为未检测。
3. **纠错跨三端衔接**：学生题目页提报示例识别问题 → 顶部切管理员 → 反馈与纠错 → 依据原件修复 → 切家长 → 更正通知。固定纠错例为校内整卷第 2 题：原件 `3/2` 被识别为 `3/8`。也可先由学生删除整卷，再由家长在相关依据中提报；后台修复后，学生删除状态保持。
4. **教材与模型维护**：管理员切校外空间 → 教材与内容 → 模拟识别、核对、限定开放 → 模型与映射 → 提出候选、检查、批准、提交启用。可以模拟基础版本冲突；其他语义规则的受控交付有独立入口。

顶部“走查工具”可切换局部识别不清、断网、处理失败、首次使用及离页待补记场景。恢复“正常处理”后在原位置重试。**“重置全部演示”会清空当前浏览器的全部原型操作**，重新装入合成样例。

## 演示边界

全部题目、判断、检查结果、身份与通知均为人工编写的合成例。每个课程只有一个资料演示槽和最近一次检测；新导入替换该槽，重开检测替换最近一次检测。这不是正式产品的保存策略。题单按预写的章节映射取样，不根据任意输入做语义判断，也不证明真实测验的覆盖充分。

状态保存在**当前浏览器、当前访问地址**的 localStorage；同一页面切角色可以走查衔接。不同设备、浏览器、端口或主机名之间不共享，也不提供多标签实时同步。未接入真实账号、后端、OCR、教材扫描处理、Evidence/Belief 或模型 API，不需要 API Key。上传仅读取文件名；请使用示例文件，不录入真实儿童资料或密钥。

笔迹区可保存演示笔画，不做手写识别，也不能代替 Android 实机对压感、防误触和性能的验证。语音输入使用可编辑的固定转写样例，不访问麦克风；播放使用浏览器朗读能力，是否有合适的中文声音取决于设备。原型中不存在真实的双向语音服务。

初始“已记录 12 分钟”、补记和未知时长只演示时间表达，不采集真实使用时长。管理员审核、冲突及受控交付只切换演示状态，不执行真实治理、事务或质量校验。前端的访问限制用于核对产品流程，不能作为服务端安全验证结果。
