# DeerMind 三端交互原型

这是此前 Development Phase 4 的产品交互走查工具，采用 Vue 3、TypeScript 和 Vite，对应[已归档的 Product and Domain Foundation](../../doc/mvp/archive/foundation/DeerMind_MVP_Product_and_Domain_Foundation_v0.1.md)。2026-10-10 起保留作历史交互参考；以下范围说明、各轮安排及演示记录按原讨论语境阅读，不代表新需求已经确认。新的三阶段框架见 [MVP 文档入口](../../doc/mvp/README.md)，先评审大纲，再讨论内容和原型后续修改。本轮仅更新文档引用，未修改原型代码。

**当前范围已调整：整份试卷录入与回顾退出 MVP，学生外部资料仅录入错题。** 第 5 轮先更新章节讲解活动，其余页面仍有旧整卷样例、入口及检查记录，不作为当前需求或验收依据。学生端按目标与学习活动逐条重审（见 Foundation §9），新的页面结构仍待走查。

## 第 5 轮：章节讲解、就地追问与返回继续

直接打开 [分数除法讲解](http://127.0.0.1:5178/#/student/lesson?lesson=fractions)，或从学生首页“章节讲解”进入校内教材，选择“分数除法”。如果此前切到校外空间，先切回校内数学。建议依次走查：

1. 阅读第一段，查看图示和算式；后续内容由“继续下一段”推进，试听结束不会自动推进。
2. 在底部“情景示例”中选择预写追问，回答出现在原段下面。原推导保留，完整历史只在点击“对话历史”后展开。
3. 继续第二段，留下未发送的问题；返回教材或切到“百分数的应用”，再回到分数除法。原位置、追问和草稿都保留，刷新也可继续，草稿随所属段落保存。
4. 点击“结束本次”，查看实际展示情况的小结；没有独立作答，不显示“已经掌握”。本例结束后可回看；若要重新走查，使用“走查工具 → 重置全部演示”。

本轮仅用两个校内章节、每章三段固定内容讨论交互。自由输入不会触发真实理解或教学，仅保留并明确提示未连接语义模型；“情景示例”提供预写回应。未接入 LLM、真实语音输入或学习判断。每章一个演示进度槽不代表正式产品的会话保存策略。自测进行中进入章节讲解，会先引导返回自测；自测内求助仍结束本次检测后转讲解。两空间记录保持隔离。

具体决定和未覆盖部分见 Foundation §9.10、§12.11。下一轮先走查这一活动，再继续错题求助、检测和系统邀请的呈现。

## 第 4 轮：按教材章节查看学习情况

先打开学生端“学习情况”：顶部显示有记录章节、资料答对率、待回顾及待确认题数。点数字卡片可以筛选章节或查看统计说明；章节按教材顺序排列，答对率和题目分布并列呈现。点“百分数的应用”展开“当前情况／相关题目／变化与建议”，在相关题目中筛选待回顾题，查看原作答并继续学习。家长使用相同统计，相关题目只读。

统计来自现有合成记录，不是新增的能力推断。资料答对率为已确认答对题数除以已判定题数，待确认不进分母；无已判定作答显示“—”。原资料帮助条件未知，不能当作独立作答正确率。查看帮助、新提交的任意检测作答分别显示，尚未核验的作答不虚增正确率。学生删除原件后统计仍保留，但相关题目不提供恢复入口；家长保留相关依据只读查看。记录纠正更新数字，不能显示为学习进步。

章节详情中的“为什么这样判断？”将章节带入常驻输入框；“变化与建议”可查看本章自测安排，确认后才开始，家长只有支持咨询。独立自测尚未结束时，学生学习概况暂不展开反馈，可返回继续作答。当前用有限章节展示三层结构；章节综合分、趋势周期、完整章／节层级及真实教材映射仍需后续讨论或实际材料，不以样例默认值冻结。

三端保留常驻输入框。普通发送不自动展开历史，点击“对话历史”才查看记录，开合保留草稿。Enter 发送，Shift + Enter 换行，中文输入法确认候选不触发发送。章节讨论中的回复、操作确认单独呈现，历史按需展开。

学生和家长使用同一套合成学习判断，按角色提供不同后续操作；两个课程空间保持分离。管理端可以从对话提出本章模型维护，建立候选后仍需独立检查、审核和提交。传统页面按钮继续可用。对话中的删除操作确认具体资料，旧卡片在对象被替换后失效；资料删除后，相关原件的旧对话内容也不作为恢复入口。

**对话当前是情景原型。** 展开“情景示例”后，点击明确标为“固定情景示例”的表达，才会进入预写回复或操作卡；没有用关键词识别任意输入。自由输入会保留并明确提示尚未理解或执行，不调用 LLM。已确认方向不依赖这些预写实现，真实意图理解在工程阶段接入语义规则与模型。

同一页面内切换路由可继续对话，按角色和课程隔离。全局对话面板及草稿暂存在浏览器内存，刷新清空；家长已发送内容另进入现有“我的咨询”，整段删除会同时清理面板副本。此演示存储方式不冻结学生正式会话的保留和删除规则。

迭代按“小范围讨论 → 更新同一原型 → 走查 → 修正”进行。已确认原则与待试验的页面选择分别记录在 Foundation §12.9–§12.10；实现问题直接修复，新的产品取舍继续讨论，不因原型已有某个按钮就默认冻结它。

## 一键启动

电脑需要 Node.js 22.12+（也支持 20.19+ 的 20.x）；首次运行需要联网安装锁定依赖。**在仓库根目录双击 `prototype.cmd`**，脚本会安装依赖、检查类型、构建、启动隐藏的本地预览服务并打开学生首页。它与 Build 验证工程的 `deermind.cmd` 分开。

也可在仓库根目录使用以下命令，无需手动进入前端目录：

```powershell
.\prototype.cmd start
.\prototype.cmd start -Role parent
.\prototype.cmd start -Role admin
.\prototype.cmd status
.\prototype.cmd stop
```

默认地址：

| 入口 | 本机地址 |
| --- | --- |
| 学生端 | http://127.0.0.1:5178/#/student/home |
| 家长端 | http://127.0.0.1:5178/#/parent/overview |
| 管理端 | http://127.0.0.1:5178/#/admin/dashboard |

页面顶部也能切换角色。该工具栏属于原型走查工具，正式 App 不用它切换身份。后台进程会继续运行；关闭浏览器不停止服务，使用 `stop` 停止。

平板或手机与电脑连接同一可信局域网时，可运行：

```powershell
.\prototype.cmd stop
.\prototype.cmd start -Lan
```

脚本会输出电脑的局域网地址，在设备浏览器打开相应地址即可。设备必须能访问电脑的端口，Windows 防火墙可能需要允许此连接。默认只监听本机；`-Lan` 才监听局域网。可用 `-Port 5188` 更换端口，后续 `status`、`stop` 使用相同参数；`-NoBrowser` 不自动打开浏览器；`setup` 仅安装和构建。

已运行时重复 `start` 会复用原服务。修改源码后先 `stop` 再 `start`，重新构建并刷新浏览器。日志和进程标识保存在仓库 `.tmp/mvp-prototype-<端口>*`，停止操作会校对进程身份，不按端口任意结束其他服务。

## 旧原型的四条流程（含已退出范围的整卷样例）

1. **试卷到讲解**：学生首页 → 拍题/上传 → 使用示例试卷 → 确认错题 → 八折题 → 只给提示 → 完整讲解。可在文字区输入或用鼠标、触控笔在笔迹区书写；原作答与新练习分别显示。
2. **自测中途求助**：学习情况 → 从教材选择自测 → 选“百分数的应用” → 提交第一题 → 第二题请求讲解。确认后结束自测，已提交作答和草稿保留；返回检测结果，未做题仍为未检测。
3. **纠错跨三端衔接**：学生题目页提报示例识别问题 → 顶部切管理员 → 反馈与纠错 → 依据原件修复 → 切家长 → 更正通知。固定纠错例为校内整卷第 2 题：原件 `3/2` 被识别为 `3/8`。也可先由学生删除整卷，再由家长在相关依据中提报；后台修复后，学生删除状态保持。
4. **教材与模型维护**：管理员切校外空间 → 教材与内容 → 模拟识别、核对、限定开放 → 模型与映射 → 提出候选、检查、批准、提交启用。可以模拟基础版本冲突；其他语义规则的受控交付有独立入口。

顶部“走查工具”可切换局部识别不清、断网、处理失败、首次使用及离页待补记场景。恢复“正常处理”后在原位置重试。**“重置全部演示”会清空当前浏览器的全部原型操作**，重新装入合成样例。

## 演示边界

全部题目、判断、检查结果、身份与通知均为人工编写的合成例。每个课程只有一个资料演示槽和最近一次检测；新导入替换该槽，重开检测替换最近一次检测。这不是正式产品的保存策略。题单按预写的章节映射取样，不根据任意输入做语义判断，也不证明真实测验的覆盖充分。

状态保存在**当前浏览器、当前访问地址**的 localStorage；同一页面切角色可以走查衔接。不同设备、浏览器、端口或主机名之间不共享，也不提供多标签实时同步。未接入真实账号、后端、OCR、教材扫描处理、Evidence/Belief 或模型 API，不需要 API Key。上传仅读取文件名；请使用示例文件，不录入真实儿童资料或密钥。

笔迹区可保存演示笔画，不做手写识别，也不能代替 Android 实机对压感、防误触和性能的验证。语音输入使用可编辑的固定转写样例，不访问麦克风；播放使用浏览器朗读能力，是否有合适的中文声音取决于设备。原型中不存在真实的双向语音服务。

初始“已记录 12 分钟”、补记和未知时长只演示时间表达，不采集真实使用时长。管理员审核、冲突及受控交付只切换演示状态，不执行真实治理、事务或质量校验。前端的访问限制用于核对产品流程，不能作为服务端安全验证结果。

家长概况的时间筛选及更新安排、其他学生会话和检测记录的删除粒度仍待讨论；未以原型默认行为冻结这些取舍。真实教材、完整领域包、原生实机和学习效果验证另行完成，原型交付不等于 G4 通过。

## 开发与检查

```powershell
cd src/mvp_prototype
npm.cmd ci
npm.cmd run dev
npm.cmd run build
npm.cmd test
```

`dev` 使用 Vite 开发服务；一键启动服务提供构建后的静态文件。浏览器检查使用 Playwright，Windows 优先调用已安装的 Microsoft Edge；其他环境先安装 Playwright Chromium：`npx playwright install chromium`。测试独占本机 5190 端口，输出到被 Git 忽略的 `test-results/`。检查覆盖产品流程与布局，不替代真实模型或 Android 验证。

工程入口为 `src/App.vue`；三端页面位于 `src/views/`，合成素材和章节题单映射位于 `src/data.ts`，演示状态位于 `src/store.ts`。章节讲解样例由 `src/components/LessonWorkspace.vue`、`src/lessons.ts` 和 `src/lesson.css` 承载。各角色状态共享仅为方便单浏览器走查；正式鉴权和数据合同须在 Engineering 阶段实现。

第 5 轮类型检查与生产构建通过，全量 33 项浏览器检查通过；新增 7 项章节讲解检查覆盖就地追问、历史按需展开、分段推进、离页与换章恢复、空间隔离、断网、提前结束、自测入口限制、音频结束不推进及 1280×800、800×1280 布局。草稿按段保存调整后复跑这 7 项，全部通过。前端流程检查不替代实际设备和真实模型验证。
