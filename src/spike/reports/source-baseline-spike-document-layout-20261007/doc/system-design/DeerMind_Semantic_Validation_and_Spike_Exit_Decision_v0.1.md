# DeerMind 语义校验与 Spike 收口设计决定 v0.1

> 日期：2026-10-07。状态：后续设计工作的执行依据；不构成 Gate 批准或运行协议默认切换。

## 1. 决定与适用范围

采用已完成作者合同核对的三份修订作为下一步设计、实现准备与受影响验证的工作依据。撤回 AA-A02 关于开放语义可靠隔离的原工程承诺；保留必需语义校验、owner-specific 提交、用途与权限边界，明确 PASS 可出错。固定 A1/E1 必要内容和责任解释规则，采用失败轮次收束及成功 Control 后重新决策的合同。原 AA-A02 及 DENIED 不改写，后继命题没有因此获得 SUPPORTED。

采用的是规则与责任，不是现有可选 Protocol 已达到质量要求的结论。默认运行 Profile 不变；具体实现须显式绑定所用协议和工作版本。上位原则已允许派生语义出错并可更正，因此本决定不新增 Concept Architecture Reopen，也不承诺任意文本都能可靠识别。

## 3. 后继义务及验收方式

A2 的后继义务分为机械提交与语义质量。机械提交要求全部必需校验确实完成、通过且绑定正确，并满足权限、版本、依赖和生命周期。语义质量要求来源支持、归属准确、职责合法、合法正例仍可用；它由规则与 LLM 判断，有限错误不能被机械检查通过抵消。下游在既有职责内判断，不继承上游决定或权限，也不增加一个未经论证的通用 reviewer。

A1 的完整作答要求有来源的方法、可见计算及已提交最终答案判断；不完整材料不补造结果，已有答案仍判断；请求按生成前固定的合同记录归属、对象与限制。混合输入不能在失败后改用较窄 Profile 绕过缺项。E1 要求理由准确解释帮助已经承担的责任；“帮助定位、保留重算”不能写成“仍独立定位”。字段间明确矛盾、必要判断遗漏和无依据假设都作为可定位缺陷保留。

逐例验收先判断执行完整性，再判断声明义务是否满足。某一已知硬缺陷不因其他维度 PASS 变为合格；材料不足不能补为通过。本文固定具体缺陷判据，不选择未经评估的生产错误率、容忍阈值或独立准确率。样例质量评审与生产可靠性分别取得证据；模型评分与作者复核的分歧保持未决。

## 4. 功能范围与剩余补证

将完整自动诊断转教学列为拟延后能力。保留范围以活动开始时登记的目的与获准动作处理单任务输入、合法局部帮助和实际披露，不自动切换活动；不允许的动作不派发。基础 Evaluation / Learner Belief 架构路径仍保留，不以脚本评分或 Policy 自述替代。

这个安排尚不是通过验证的 STAGED。正式采用范围前，必须在提交及派发入口证明自动切换不可绕过限制、失败或未知 Control 不开启教学、Context 不偷用新活动条件，并保留失败轮次的队列边界。存在未知在途 effect 时，不能以延后生产恢复为理由释放队列。若这些限制无法实现或保留功能实际依赖自动转换，则该延后方案不成立。

| 补证事项 | 要回答的有限问题 | 完成或失败后的决定 |
|---|---|---|
| 保留范围的执行限制 | 工作合同绑定哪个 Profile；禁止的 Control 能否进入提交或派发；失败旧候选是否被消费；普通输入是否严格排队 | 限制成立后才审查 X5 阶段化；出现旁路即修正范围或实现，不开启真实批次掩盖问题 |
| A1/A2/E1 受影响内容 | 修订后完整、未完成、请求输入是否满足必要义务；已知错误和合法对照是否得到有依据判断 | 固定样例报告合格、缺陷、未决；仍有缺陷则明确实现不满足该范围，不自动增加 reviewer 或重跑 |
| E2/F2/X1/X2 覆盖缺口 | 保留四次断连、五次多结果失败，并明确新证据是否真的补到各缺失路径 | 新证据另存；失败仍为缺口，不能把安全拒绝当成功链路 |
| 原 Completion 与 Gate | 原完整覆盖、重复执行、受影响验证、复杂度和设计后果是否满足；阶段化证据是否充分 | 条件满足才评 Gate；否则保持 OPEN，变更要求须另记决定，不改历史 9/17 |

顺序是先核实工作 Profile 和执行限制，随后才冻结一次受影响补证计划。当前没有启动或批准新模型批次；原批次不重开。新计划须把输入、预算和三种结果的后续决定一并固定，结束后报告结果，不能失败后自行扩大。

## 5. 原验收与当前阶段

本决定保留 [Spike §17](DeerMind_Consolidated_Architecture_Spike_Design_v0.1.md) 的完整场景、重复执行和否定后受影响验证要求，保留 Gate E/F 标准，不将旧 9/17 改为新分母。Gate E 的修订或阶段化路径不是免除原 Completion 的自动授权。

当前是证据评审及设计修订，三份合同已有明确工作落位；X5 入口证据、受影响语义质量和原覆盖仍未完成。工作依据采用、固定批次关闭、原 Spike Completion、正式 v1.0 冻结各是独立状态。本文完成前两者的设计记录，不声称后两者完成。
