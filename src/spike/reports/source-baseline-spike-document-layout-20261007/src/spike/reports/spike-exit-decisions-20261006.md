# Spike 剩余八项处理建议

2026-10-06，待讨论草案。建议结束逐例调优，先把已有结果转为设计决定，再决定哪些验证必须继续。17 项均已有评估，9 项满足完整验收范围；“有评估”不等于“已通过”。A2 DENIED、其余七项 INCONCLUSIVE 和 Gate E/F OPEN 保留。

| 项目 | 已经发现的问题及设计影响 | 建议处理与收口条件 |
| --- | --- | --- |
| A1 观察是否有用 | 15 次计划中仅尝试 7 次，3 次提交、4 次合同或运行失败，另有有用性争议；不能证明当前观察合同稳定可用。 | 保留不读取能力信念的职责边界，明确每种观察必须包含什么。合同及失败处理确定后结束本轮分析；新合同的模型质量留作后续验证，原覆盖缺口保留。 |
| A2 语义职责边界 | 已出现不允许的教学建议通过校验并取得 Observation standing；“校验通过足以保证职责正确”的原假设被否定。 | 必须修改设计依赖：PASS 不替其他职责作担保；下游在自身职责内依据原始来源和实际帮助作判断，仍使用规则与 LLM。明确错误传播路径与缺失、失败处理后收口；不宣称消除了语义误放。 |
| E1 Policy 判断 | 固定评审放过明确矛盾，另有历史评分争议；格式修订未证明语义质量改善。这个反例不单独证明 AI 无法承担 Policy。 | 保留 AI 判断与机械权限检查分工；Policy 理由不成为学习者能力事实。停止反复围绕同一反例调优，将质量目标、成本和评测方法留作后续验证；v4 保持实验性。 |
| E2 严格串行 | 15 条真实路径中 2 条因断连未完成；已有路径支持串行机制，完整覆盖不足。 | 明确失败轮次何时结束、效果未知如何记录、何时释放队列。优先复用已有局部证据；网络恢复验证建议放到后续运行验证，旧缺口不得计作通过。 |
| F2 工具与权限 | 25 条真实路径中 5 条返回多个结果，20 条完成；25 条脚本攻击均被拒绝。模型输出可用性与后端权限保证不同。 | 保留后端身份和精确范围检查；非法返回明确失败，不能挑一个结果继续执行。权限结论按原范围保留，模型单结果可用性单独验收。 |
| X1 更正后重决策 | 1 条因断连未完成；4 条已完成路径使旧候选失效并在收束后重新决策。 | 保留更正、依赖失效和重决策机制；明确断连后的失败状态。缺失真实路径建议后续补验，不能直接把局部机制支持改成完整组合通过。 |
| X2 撤销后拒绝效果 | 新版本替代 5/5 完成，显式撤销 4/5；1 条未到达撤销点。 | 保留替代与撤销的区别、执行前重查。未到达撤销点的路径不能算撤销覆盖；后续补验单独列入计划。 |
| X5 诊断转教学 | 5 条真实完整路径均未完成，4 个效果边界未覆盖；上游观察合同失败阻塞了组合验证。 | 先定观察合同、成功 Control 后的转换及新独立机会条件。建议将这条链列为未验证功能，后续单独验证；其实际展示和能力判断不得据现有证据宣称完成。 |

四项机制审查已完成：E2 13/15、F2 20/25、X1 4/5、X2 9/10，共 46/55 条真实路径完成；其余四条断连、五条返回多个结果。已执行检查没有发现架构 falsifier，但缺失路径仍不能算通过。建议保留串行、后端权限、更正失效和执行前撤销重查，不为获得全 PASS 重跑旧批次。E2/X1/X2 采用整合草案的失败收束条件；F2 拒绝整个多结果响应，不挑选其中一个执行。模型请求可用性、真实缺失路径和生产恢复另列验证要求，是否移交须明确调整阶段范围。证据见[四项机制审查](remaining-mechanism-review-20261006.json)，失败与衔接合同见[整合修订草案](../../../doc/system-design/DeerMind_Validation_and_Interaction_Closure_Revision_v0.1.md)。

退出路径有两个选择。保持原范围，就必须完成受影响设计修订和缺失验证，当前不能退出原验收。建议采用阶段收口：先结束本轮实验，完成八项设计后果和后续验证安排，再讨论是否正式调整阶段范围及进入下一阶段的条件。依据[原退出规则](../../../doc/system-design/DeerMind_Consolidated_Architecture_Spike_Design_v0.1.md)，移交缺口不能自动关闭 Gate，也不能把 9/17 改成 17/17；正式范围调整须保留旧假设、结果与新验收条件的对应关系。

下一步只讨论三项取舍：语义 PASS 能承担多强的保证；哪些模型质量与网络可用性要求放到后续阶段；X5 未完成时允许进入下一阶段的功能范围。随后更新设计与退出条件。只有某个取舍缺少决定性证据才提出有限验证，预先写明预算、成功与失败各如何收口。本轮不新增模型调用。

证据索引见[当前进度](validation-progress-v1.json)和[逐项设计后果](design-closeout-review-20261005.md)；语义反例和格式失败分别见[v2 评审](policy-v2-real-review-20261006.md)、[v3 识别](policy-disposition-real-20261006.md)。
