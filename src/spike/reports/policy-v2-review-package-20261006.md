# E1 v2 有限语义评审包

日期：2026-10-06。完整输入与离线评审执行器已交付，真实模型执行、独立标签审阅和服务端 token 预算尚未完成。

## 本次交付与范围

有效入口为[最终材料 manifest](../review-packages/policy-e1-v2-final/manifest.json)。[完整候选与 Context](../review-packages/policy-e1-v2-final/cases.json)包含十四个合成案例和四个原争议候选；[实际评审请求](../review-packages/policy-e1-v2-final/requests.json)包含每例一次语义校验及一次测试评分，共三十六个请求。生成器为 [prepare_policy_v2_review.py](../prepare_policy_v2_review.py)，输出目录已存在时拒绝覆盖。

十四个合成案例具备完整 PolicyOutcome 字段、精确来源引用、活动与行动材料。来源内容被改动时使用新的合成身份；未改动的行动目录保留原身份和精确 payload。缺失原作答案例明确移除作答及其 Observation，保留评审材料缺失说明；效果未知与展示确认分别有声明为脚本来源的发生记录；允许完整讲解的正例提供获准 Control 和相应活动约束。上游建议冒充授权的反例刻意包含不允许的行动，其不合法性单独记录，不能拿它的拒绝充当纯语义隔离证据。

四个历史案例按原候选 digest 从原始 JSONL 校验完整候选，并提取当时语义评审消息中的完整 Context 和 candidate。新请求只换用 v2 评审规则，保留 v1 来源身份、原候选及其争议状态；这是新规则对旧内容的离线复核材料，不是重建 v2 生产提交，不是原结果被修改。

[作者预期](../review-packages/policy-e1-v2-final/author-expectations.json)单独存放，不进入模型消息。合成候选的语义预期仍是作者判断，评分只标注原设计涉及的维度，其余维度和整体 utility 预期不擅自补为 PASS。四个历史候选不附新判决。尚未完成独立审阅，不能把模型与作者一致称为已证明正确。

本包仅评审固定候选，不进行行动生成、正式提交或执行。它不能单独完成 E1 开放决策质量验收，也不覆盖字段投影部署、E2 或 X5。A2 DENIED、E1 INCONCLUSIVE、9/17 及 Gate E/F OPEN 保持。

## 执行器、预算与本地检查

[评审执行器](../run_policy_v2_review.py)在执行前检查材料及来源摘要，使用无重试、最多三十六次调用的适配器。只解析 requests，不加载作者标签；逐请求保存原始适配器记录及结果。语义 FAIL/UNRESOLVED 是有效测量结果，网络或结构错误才计执行失败；连续三次执行失败后停止，剩余请求保留 NOT_RUN。CLI 当前只运行阻断网络的离线对照，不读取 API key 配置。该范围内没有生产提交或行动执行入口。

[离线结果](../runs/policy-v2-review-offline-v3/summary.json)验证三十六个请求逐一通过适配器并保留注入的 UNRESOLVED，以及三次结构失败后停止、余下三十三项不执行。共三十九次脚本传输、零真实模型调用；这些注入状态不计入语义结论。未重复前一阶段的 285 项机械回归。审核还逐项比较三十六条实际脚本消息与准备请求，见[范围审计](policy-v2-review-package-audit-20261006.json)。

最长消息序列化为 9,647 字符，低于本地适配器 16,000 字符上限；含输出合同的最大请求为 10,567 UTF-8 字节。字符、字节与模型 token 不等价，服务端上下文、输出余量及实际模型身份仍需执行前核对。当前提出的一轮三十六次上限只是有限方案，不是已启动或预约的真实批次。

开发记录保留：最初准备目录 policy-e1-v2 中的合成行动引用被重新命名，已被最终目录替代；旧 manifest 不是有效输入。离线 v1 因 LLMConfig 不接受 retries 构造参数而在准备阶段失败；离线 v2 因默认端点不支持严格输出，在传输前失败；修正后 v3 完成上述控制。前两次均零实际传输，不作为模型质量失败或偷偷替换真实运行。

## 下一步

先审阅完整合成候选而非只审片段，明确作者标签是否需要外部独立复核及如何保留分歧；核对服务端 token 预算与运行模型后，再决定是否执行这一轮固定评审。即使执行，报告也应分别呈现正例可用性、反例误放、未决、执行失败与历史争议复核，不能只报一个总通过率。有限评审完成后做范围结论，不自动追加次数或修改标签再跑。
