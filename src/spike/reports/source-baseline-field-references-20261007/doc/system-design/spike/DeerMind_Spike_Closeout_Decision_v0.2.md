# DeerMind Spike 阶段收口决定 v0.2

日期：2026-10-07。状态：后续工作收口依据；Gate E/F 保持 OPEN，System Design v1.0 未冻结。本文承接[阶段收口草案 v0.1](DeerMind_Spike_Closeout_Decision_Draft_v0.1.md)和[语义校验设计决定](DeerMind_Semantic_Validation_and_Spike_Exit_Decision_v0.1.md)。原 Spike 设计、实验输入和结论继续保留。

## 1. 当前决定

本轮模型试验结束。固定工作配置已经完成离线集成，但一次真实尝试在首项失败后关闭，未取得声明范围的质量支持。该配置保留为未验收的实验实现，不用于宣称真实 Observation、Policy 或教学闭环已经可用。后续工作先处理已定位的表示缺陷并审查设计接口，不继续追加提示词或模型试跑。

Spike 可以以“发现问题、否定假设并形成设计后果”结束一轮探索；某个实现没有达到要求，应记录为未验收，而不是继续测试直到通过。当前结束的是固定试验和追加调优过程。原 Spike Completion、Gate E/F 和正式 Build 各有自己的条件，不能因本轮停止而自动满足。

原 AA-A02 的 DENIED 保留。替代它的工作合同要求 owner-specific 的必需校验、权限、版本和依赖检查，并承认获准的语义 PASS 仍可能出错。这维护 SI-04 的正式提交路径和 SI-13 的受控推理责任，但不能将一次有效 PASS 提升为内容正确的保证。实际语义质量仍需在声明范围内取得证据。

## 2. 两个缺陷及其设计后果

[一次真实尝试](../../../src/spike/reports/restricted-working-real-20261007.md)只调用模型一次，耗时 6.802 秒。候选动作是“再检查一下 42÷6。”，理由却称“没有替代任何定位工作”。模型引用了这段理由，仍把定位责任规则判为 PASS；随后又对空的 defer_condition 返回空引用，被本地证据展开拒绝。零份有效审查，其余九项未运行；失败轮已收束，没有该 Policy 的正式提交或动作执行。

引用缺陷属于表示合同问题。现有字段登记包含空字符串，返回 schema 允许空 quote，本地展开又禁止空 quote；三者不一致。确定的后继设计是让模型选择来源字段编号，由运行时读取该字段的精确原文，不再要求模型复制原文或计算字符范围。可引用登记只包含非空字符串，编号绑定本次 exact candidate、Context 和 material view。模型不能提交自写引文、未登记编号或另一候选的编号；运行时不能模糊匹配或补写证据。

空值仍保留在候选中，并接受字段覆盖和已有 outcome 结构检查。它不成为 prose quote。Execute 的空 defer_condition 可与非空 outcome 字段及动作材料一起审查；Defer 仍需具备合同要求的具体未来决策条件。排除空值的引用入口不等于排除该字段的必要审查，也不允许用“不适用”替代应有的条件。字段编号只是证据定位，SUPPORTED、CONTRADICTED 等含义关系仍由规则与 LLM 判断。

这个方向尚未实现。实施时应修订可选返回合同及其本地校验，保持同一次 semantic review、完整 S1–S5、精确来源和提交时重查。旧 v4 返回保持原状，新合同须有显式版本绑定。至少验证空字段仍被覆盖、空字段不能被当作引文、非空字段原文可精确展开、未知编号和错误绑定被拒绝，以及已有正常与矛盾 disposition 的机械处理保持不变。这些是本地契约验证，不需要 API key；通过后只能声称表示机制已修复。

内容误判属于独立的质量缺口。模型看见了错误定位责任陈述，仍认定它与定位提示相容；空引用修复不能证明这项判断会正确。现有规则已经明确“帮助定位、保留重算”，不需要为了这个反例再增加通用 reviewer。保持该规则与反例，将误判作为后续质量评估材料，不能在运行时硬编码这句话的拒绝规则，也不能删去必要理由来绕过审查。一次输出无法确定模型内部成因，更不能证明该问题永远无解。

本次未形成有效审查，因此总体结果为 INCONCLUSIVE；原始 PASS 的内容误判另行明确记录。本地契约拒绝没有识别定位矛盾，不能计为语义判定成功。错误候选没有发生实际效果，也不能被写成此次出现了错误正式提交。

## 3. 各项结果的处置

| 项目 | 当前处理 | 仍未获得的结论 |
|---|---|---|
| A2 | 撤回开放语义可靠隔离的过强保证，采用可出错的语义判断与强制提交约束；保留原两次错误提交。 | 后继质量合同没有取得真实支持；原 DENIED 不被替换。 |
| A1 | 保留生成前声明目的，以及完整作答、未完成作答和请求各自的最低含义要求。 | 此次六项正常输入均未运行，不能证明修订后的 Observation 可用。 |
| E1 | 保留来源支持、定位责任、预期披露和字段一致性要求；修订引用表示，记录原始内容误判。 | 表示修复尚未实现，语义质量和原教学评分争议未解决。 |
| E2 | 保留严格串行、失败收束及提交和执行前复核。 | 原 13/15 路径仍缺两条；本地失败收束不证明生产异常恢复。 |
| F2 | 保留委派范围和后端权限检查，多结果输出整体拒绝。 | 原 20/25 真实路径仍缺五条，合法工具可用性没有被安全拒绝替代。 |
| X1 | 保留更正导致旧依据失效，以及新轮重新决策。 | 原 4/5 路径仍缺一条。 |
| X2 | 保留 supersession、精确撤销及派发前权限复核。 | 原 9/10 路径仍缺一条，缺失的 revoke 路径没有补齐。 |
| X5 | 自动诊断转教学继续列为未验收能力；固定活动入口仅作为阶段化方案的局部机制证据。 | 原五条完整路径及四个效果边界缺口保留，整个阶段化范围尚未成立。 |

固定活动入口在本地脚本和同步 mock 范围内限制精确协议、活动 envelope 和允许动作，并在提交、Intent 和派发处检查。已有测试还验证启用前尚未执行的 Control Intent 被拒绝、队列边界和独立 Evaluation owner 保留，见[入口实现](../../../src/spike/reports/restricted-working-entry-20261007.md)与[集成审计](../../../src/spike/reports/restricted-working-integration-20261007.md)。这些证据支持保留该局部机制。它们没有取消远端在途 effect，也没有证明保留功能的真实语义质量；因此不批准将完整 X5 标为 STAGED。固定活动内的提示同样可能帮助定位，Evaluation 必须使用实际披露历史，不能把“未切换活动”解释为“未提供帮助”。

基础 Observation、Policy、提交和权限责任继续保留。它们是闭环所需能力，不能整体移交为后续可选功能。某项能力不可用时，系统应表达失败或未决并按合同收束；这可以保护效力边界，但不能代替有用性验收。

## 4. 原完成条件与 Gate 的当前判断

[原 Spike §17](DeerMind_Consolidated_Architecture_Spike_Design_v0.1.md)的完整执行要求尚未满足，完整覆盖仍为 9/17。全部 12 项架构假设和五项组合已有分类和设计后果，统一报告与历史证据已登记；已评估不等于完整执行，九条 E2/F2/X1/X2 缺失路径和 X5 缺口继续保留。本决定不修改原 Completion 条件，不将关闭固定批次算成补齐覆盖。

[路线图 Gate E](../DeerMind_System_Design_Roadmap_v0.6.md)允许验证支持、否定后完成修订、充分证据证明无需试验，或有 Invariant 保持证据的阶段化安排。A2 已有明确修订方向，但不能据此一并关闭 A1/E1 的未决质量要求；X5 仅有局部入口证据，尚不足以批准整个阶段化。E2/F2/X1/X2 的真实覆盖缺口也没有被重新分类为支持。当前 Gate E 保持 OPEN，后续评审逐项选择适用路径，不能以 INCONCLUSIVE 或“开发时再看”作通过依据。

Gate F 同时要求明确运行、状态、AI、一致性、版本合同及一致的总体和专项 Baseline Set。当前三份修订只采用为工作依据，四份未修订专项仍需核对相邻接口，表示合同的后继实现和基础语义可用性也没有形成完整验收依据。故 Gate F 保持 OPEN；当前可继续契约修复和设计评审，尚不能冻结 v1.0 或进入正式 Architecture Validation Build。

这个判断没有新增整套设计已被否定的结论，也没有宣布所有 Gate 条款已经全面评审。它定位足以阻止当前通过的具体条件，保留未评审部分，而不是用补齐本地测试数量替代 Gate。

## 5. 下一步及停止条件

下一步只实现上述字段引用合同并完成必要本地检查，同时记录显式版本与旧输入的关系。若契约无法兼容现有必要审查，停止该实现方向并记录原因；若通过，登记为本地表示修复，语义质量仍未验收，不自动启动真实尝试。随后核对工作文档集与相邻专项的受影响接口，形成可以逐项评审的 Gate 处置清单。

后续确需真实质量验证时，先说明它将决定哪项架构或功能取舍，再固定范围、正负例、必要内容、模型参数、调用和时间上限、审阅方式，以及支持、反证、执行失败和未决各自的后续决定。应同时衡量合法输入能否完成和已知错误能否被识别；结构失败、全部拒绝与未运行都不算识别成功。生产错误率和容忍阈值尚未确定，本决定不替它们指定数值。旧批次不重开，新计划失败后不得自动扩大或调优。

重新打开已关闭试验需要一个新的明确问题和工作决定，而不是“继续试一次”。若出现权限旁路、失效依据继续执行、失败候选取得正式效力或未知在途效果时释放队列，应立即审查对应机制；这些是效力边界问题，不能以模型质量未验收为理由容忍。

工作文档集仍采用[语义校验设计决定 v0.1](DeerMind_Semantic_Validation_and_Spike_Exit_Decision_v0.1.md)登记的版本。本决定补充其试验完成后的处置和字段引用方向；具体 Protocol 实施仍须显式登记，不默认切换。历史结果、证据摘要和当前待办以[验证台账](../../../src/spike/reports/validation-progress-v1.json)为准。
