# Policy 引文字段表示：局部实现与验证

日期：2026-10-06。v4 表示修订及固定本地验证完成；真实协议可用性与语义质量未验证。

此前 [v3 固定识别批次](policy-disposition-real-20261006.md)在三次连续合同失败后关闭，零有效校验，后三例未运行。失败涉及额外字段、将数组当作字符串引文以及字符位置错误；没有输出截断。这次只修订引文表示，不改写原批次或补跑其未运行项。

新增 opt-in [E1 v4 协议](../protocols/policy-e1-v4.json)，语义格式为 policy-disposition-fields-v2。运行时枚举冻结候选和可见上下文中顶层字符串字段，为每项分配 handle。模型从 candidate 或 context 的原字段读取内容，返回 handle 和非空精确引文，不计算字符位置。消息中的 quote_registry 只携带字段编号、字段名和来源 ref，不重复传输原文；内部注册表保留原文用于核验。数组、对象和数字没有字符串引文编号，原结构化引用和权限检查继续生效。

[policy_field_quotes.py](../foundation/policy_field_quotes.py)要求引文在编号对应的字符串中唯一出现，包含重叠的第二次命中也拒绝。唯一匹配后按 Unicode code point 计算位置，再复用既有裁决一致性检查。未知编号、空引文、改写、空白规范化和歧义均拒绝；重复短引文需由模型选择更长的唯一原文，运行时不会猜测其意图。实际严格返回 schema 的编号 enum 由该次可见字段确定，提交时重新生成映射并复核绑定。

S1–S5 完整声明、finding/check/整体状态一致性、候选摘要、Context、规则和受信材料记录绑定不变。正确字段不能抵消已经声明的矛盾；FAIL 与 UNRESOLVED 均不得提交。隐去来源不会进入编号清单，已取得的评审可以复用，每个候选仍仅允许一次尝试。没有新增自然语言分类器、语义判断调用或隐式重试，v1/v2/v3 入口保留，v4 未默认启用。

[固定全套运行](../runs/policy-field-quotes-v1/summary.json)通过 311 项测试，无失败、错误或跳过，包括 [十二项新增用例](../tests/test_policy_field_quotes.py)。用例覆盖生成至校验与提交、动态编号 schema、非字符串排除、Unicode 位置、重叠重复拒绝和长引文消歧、未知编号、空引文、改写拒绝、顶层 PASS 与已声明冲突不一致、隐去视图及有效 UNRESOLVED 拒绝、提交时编号篡改复核。另保留内部一致的错误语义 PASS 可以提交的反例，明确机械绑定不能发现模型漏报的含义冲突。

[本地评估](policy-field-quotes-assessment-20261006.json)核对 187 个冻结输入、14 个运行产物、12 份快照和 8 条脚本模型记录，七条实际校验消息的编号均定位到原可见字符串。已有 484 项证据哈希通过核对；两个改动源文件的[历史字节](source-baseline-policy-field-quotes-20261006/index.json)归档保留。入口为 [run_policy_field_quotes.py](../run_policy_field_quotes.py)，固定目录创建一次，网络阻断，无网络尝试、真实模型调用或失败批次替换。

开发阶段首次十二项局部测试中，五项因清单重复携带原文而触发 InputLimitExceeded；改为位置清单后十二项通过，再执行一次固定全套运行。未知编号也由动态 schema 在适配器层直接拒绝，测试按实际错误层修正。没有提高 16,000 字符输入上限；记录中的最长消息为 14,823 字符，剩余余量较小，尚未核对原六例完整请求和服务端 token 预算，不能据此宣称真实调用已准备完成。
