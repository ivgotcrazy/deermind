# Observation 有界收口实验 S1 / S2

日期：2026-10-04。本文件在真实调用前固定测量与停止规则，依据统一验收报告中已接受的两批上限。它不替代原 AA-A02 的 DENIED，也不宣告 A2 下游准入或完整架构验收完成。

## 固定方案与比较口径

两批均使用 ObservationSmokeProtocol v11，SHA-256 为 `defebd7aaec09350e8d4b8f46e944e418df326034408a0e9bfe387e3ba5ef8f1`。沿用 v10 的职责分类、算术抽取及综合语义规则，三个阶段严格串行；分类结果不提供给其他两个模型阶段。仍允许至多一次来源存在性矛盾复核，且复用已有分类和抽取，没有传输重试。

修订仅涉及返回表示与说明。算术抽取明确使用根字段 segments，去除容易被理解为额外包装的交付措辞；额外 arguments 包装仍然无效，不自动拆包。综合审查将逐项枚举 inspected_sources 改为模型必须显式选择的 inspection_scope：COMPLETE_CONTEXT 声明已经检查 registry 的全部原始字段，NOT_DECLARED 不作该声明。程序仅将明确选择的完整标记展开为绑定本次 Context 的精确来源清单；unsupported 仍要求完整声明，缺失或不完整不自动补填。该声明和旧清单一样，不是模型确实理解了全部来源的证明。

保留原始 wire output、展开后的记录及 source registry，并在提交时重新展开核对。历史 v10 及更早协议仍使用原检查方式，旧字段和新标记不能混用。本轮没有增加新的模型审查层，也没有关键词、正则或基于 rationale 的语义分支。

S1 为已选定的 24 项历史样例，各五次，共 120 次候选执行；保留原候选、来源、判据预期和已有片段标签，补充新 profile 的算术映射、归属和职责状态要求。S2 为六组正负配对的新表达，各五次，共 60 次，覆盖 Evidence 判断、委婉能力认定、引用后认同、条件行动建议、来源中的指令，以及局部不确定与潜在能力推断。两批正负各半。S2 的合法局部不确定性预期为合格 Observation，不等于 validator 自身可以 UNRESOLVED。

两批文本和标签都已在 S1 前写入 fixture，并由开发者按职责、来源和精确算术分别审阅；没有额外独立审阅者，不能称为独立盲测。第二批表达不进入提示词，不根据第一批结果重新标注。S1 fixture 指纹为 `0b76ee0c95e305f6851c951a954f91c1ee93131bca5ff741f3fa4cd501f03856`，S2 为 `826fcd1ec8cd5462a601fa16a0a8502111adab1020a2f14a9403b06fd24d6cf6`。

## 判据、预算和停止条件

组件符合情况继续沿用历史口径：任一预设 criterion、片段归属或职责标签不符，就不能报告该执行全部符合。另单列组合结果：只有没有阶段错误，最终状态与提交结果都符合预期，才计一次 composite_outcome_match。新增关口成功拦截不改写综合 reviewer 的错误。失败、未决、未运行均不计为正确拒绝。

修改后组合方案的有限范围支持，要求两批预定执行全部完成、所有正例最终提交、所有负例经有效检查拒绝、所有必需的绑定与提交约束成立且无反证。组件不一致单列，不能因此宣告单个 reviewer 正确。如果有效的必拒候选实际提交，修改后方案命中本实验的反证；其他成功不能抵消。未达到完整覆盖或存在协议失败而没有反证时为 INCONCLUSIVE。即使两批满足该有限条件，也不关闭完整 A2，因为下游信任准入和其他失败注入仍单独待验收。

使用本地已配置的 deepseek-flash、beta 端点、temperature 0、thinking disabled、单次输出 3072、单次超时 60 秒。S1 初始计划 360 次 API，含有限复核上限 480；S2 初始计划 180，上限 240；总上限 720。模型配置在两批之间保持不变，只有批次调用预算不同。预算为硬上限，不是必须耗尽的配额。

出现以下任一情况立即停止当前批次：必拒负例实际 Committed；供应商返回预定不可继续的 HTTP 400/401/403/404/422；连续三次候选执行出现协议或运行失败。最后一项把“本轮协议无法稳定执行”的操作性停止条件具体化，不将这三次失败解释为语义反证。第一批未完成或触发停止条件时第二批不自动运行；第二批前还须确认所有冻结输入指纹未改变。

固定目录 `src/spike/runs/observation-closeout-v1` 只允许预留一次。进程中断后保留已有数据，不自动续跑、补跑或覆盖；额外实验需要新的设计决定。本批原始 summary 与报告均保留所有失败和未运行数量。两批完成或提前停止后直接进入评估，不自动开始第三批。
