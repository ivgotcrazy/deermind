## 未通过项目的处理

| 项目与原要求 | 候选设计的处理 | 仍未满足的要求 |
|---|---|---|
| A1：Observation 忠实形成可用的任务表现描述 | 在生成前声明目的与 Protocol。完整作答必须描述可见方法、局部计算，并独立判断已提交最终答案；不完整作答保留未知，但已有最终答案仍需判断。请求描述按预先声明的请求合同处理。 | 原 7/15 次尝试中只有三次正式提交，四次执行失败、八次未运行，方法质量争议仍存在。澄清合同不修复旧候选，也不证明真实形成质量。 |
| A2：语义边界保证 | 必需校验缺失、失败或未决仍拒绝提交；PASS 只表示可出错的审查意见。下游继续自身职责内的语义判断，上游 PASS 不授予下游权限。 | 两次错误正式提交仍是错误，原假设 DENIED。需要明确批准替代原强保证的假设及其验收方式；不能下调原失败判据，或把多次 LLM 同意当作正确性证明。 |
| E1：Policy 合法性与教学价值 | 理由如实说明已经提供的定位帮助与仍由学习者承担的计算责任；不确定性须有与决策相关的事实依据。 | 原四项质量争议及后续错误 PASS 均保留。测试专用 grounding、responsiveness、responsibility_cost、consistency 四维不因新文档而通过；最低质量义务和接受方法还需评审。 |
| E2：串行会话与执行前复核 | 常规处理严格串行，失败明确收束后才释放队列；已有实际 effect 仍须处理或核对。 | 13/15 条路径完成，两次 provider 断连造成覆盖缺口。旧有限覆盖不证明所有异常恢复；远端取消、重启恢复和 effect 核对未由本地 mock 证明。 |
| F2：委派权限与合法工具使用 | 保留后端权限、字段绑定和 effect 边界，不依赖语言扩大权限。 | 20/25 条真实路径完成，五次多结果响应被拒绝。脚本攻击拒绝不能替代缺失真实路径，字段错误的替代请求不能证明合法工具可用性。 |
| X1：纠正与依赖提交组合 | 保留正式提交、旧依据失效与派发前复核。 | 4/5 条路径完成，一次生成断连。没有观察到机制反例不等于完整覆盖。 |
| X2：supersession / revoke 组合 | 保留当前权限、依赖与 effect 前置条件检查。 | 9/10 条路径完成，其中 supersession 五次、revoke 四次；一次校验断连使 revoke 路径缺失。 |
| X5：失败诊断后请求教学的完整链路 | 失败候选不成为正式依据；新请求可读取获准原始材料。请求本身不改变活动或授权。获准 Control 实际成功且结果处理完成后，才在新活动下形成并校验教学决策。 | 原五次尝试无完整路径，四个真实 effect 分支未运行。合同明确不代表完整真实链路已验证；是否延后自动切换须另有明确功能范围和 Invariant 保持论证。 |

以上八项不能整体移交为“以后处理”。A1/E1 的最低来源忠实性、职责边界与必要内容义务，以及 A2 的必需校验、提交、权限边界，都属于基础链路。学习请求是否包含教学意图等开放含义继续使用语义规则与 LLM 判断，不引入关键词分类器。生成结果漏项不能反向缩小目的或降低合同；旧失败轮也不能通过后续请求恢复提交资格。

E2/F2/X1/X2 合计 46/55 条路径完成，四次断连、五次多结果失败。这个有限结果支持保留已实现机制，并明确九条缺口，不支持擅自缩小原覆盖要求或宣称生产恢复成立。其他已支持项目的范围限制也继续保留。

## 阶段范围与正式退出

原 Spike §17 的完整覆盖要求仍未满足。路线图 Gate E 允许明确阶段化能力，但需要证明延后不破坏 Invariant；这不是将任意未通过项目从分母删除。若拟延后 X5 自动活动转换，必须明确下一阶段开放哪些操作、哪些路径依赖转换、如何维持当前活动权限及帮助披露约束，并给出相应证据。当前文件只定位这些要求，尚未提供完整论证或批准延后。

正式评审应先决定 A2 假设修订和 A1/E1 最低义务，再审定阶段范围及适用的 Completion 条件，最后分别评估 Gate E/F。保留原验收条件时，未满足的路径继续阻止正式退出；修改条件时，应记录修改理由、适用范围与证据，不追溯更改原实验结果。只有满足相应 Gate 与基线冻结要求后才能进入正式 Build，当前候选不授权 v1.0 冻结或阶段进入。

本次文档整合完成后，不自动启动新批次。确有决定缺少证据时，先明确它阻塞哪项决定、需要什么有限证据及停止条件，再讨论验证。现有结果和源摘要以[验证台账](validation-progress-v1.json)及[验证报告](DeerMind_Architecture_Validation_Report_v0.1.md)为准。
