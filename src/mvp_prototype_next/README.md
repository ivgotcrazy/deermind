## 1. 本次交付与基线

本目录作为后续融合工作的起点。学生端和管理员端均复制各自原始项目，复制时页面内容、示例数据、样式、交互、配置和依赖锁文件保持原样；本批在这套基线上接入获准能力，具体修改见 §6。此前 `mvp_prototype/src/integrated` 中改写的学生页面不作为界面基线。

```text
src/mvp_prototype_next/
├── student/                 以原始 V2 学生端为基础，接入已确认能力
├── parent/                  保留旧版当前家长界面、示例数据和本地操作
├── admin/                   新版后台基线上的统一模型工作台与三任务
├── prototype.cmd            M01：启动、停止、状态、构建和重启入口
├── scripts/                 启动脚本、静态服务、真实对话接口及保存
├── BASELINE_MANIFEST.json   来源、相对路径、大小及 SHA-256
└── README.md                本清单及后续确认记录
```

- **复制范围：** 50 个源文件、入口和项目配置文件，包含两份依赖锁文件；逐文件字节和 SHA-256 一致。
- **M07 家长基线：** 另外复制 22 个家长共享组件、依赖、样式及包配置文件，来源与校验值见 [家长基线](parent/BASELINE_MANIFEST.json)。新增独立入口和构建配置；复制文件中仅 `state.ts` 调整本地存储键，其他 21 个文件与旧版一致，原来源文件未改动。
- **未复制：** 依赖安装目录、构建产物、缓存、日志、环境密钥和运行数据。这些不是原始页面定义。
- **当前可用程度：** 六下数学对话接入真实模型，讲解内容、教学模式和阶段由实际输入及模型回复决定；原有上下文页面不被替换。其余学科学习空间仍保留原 V2 演示逻辑，不调用真实模型。首页“更新”可维护课堂进度。聊天中的检测题可开始、提交或求助；随堂练习可直接提交。停止与重试在相应状态出现，检测后的反馈继续显示在原对话中。
- **既有环境：** 三个原目录全部保留。5178 旧服务和旧启动脚本未改动；新服务在 5181，未导入、覆盖或清理旧浏览器记录和服务端会话文件。

原样保留并不表示原始演示数据已经符合正式能力模型或当前试用课程。发现的差异在 §4 登记，不能借迁移之名自行修订。

### 1.1 启动与查看

从仓库根目录执行下面的命令；也可双击本目录的 [prototype.cmd](prototype.cmd)，默认启动并打开学生端。

```powershell
.\src\mvp_prototype_next\prototype.cmd start
.\src\mvp_prototype_next\prototype.cmd start -Role admin
.\src\mvp_prototype_next\prototype.cmd start -Role parent
.\src\mvp_prototype_next\prototype.cmd status
.\src\mvp_prototype_next\prototype.cmd stop
```

- **页面地址：** [学生端](http://127.0.0.1:5181/student/)；[家长端](http://127.0.0.1:5181/parent/)；[管理员端](http://127.0.0.1:5181/admin/)。三端由同一个服务提供，停止操作会同时停止三端。
- **首次启动：** 自动安装锁定依赖、检查类型、构建三端并启动隐藏的后台进程。已运行时再次 `start` 只打开所选端，不重复启动。可加 `-NoBrowser` 只启动服务。
- **后续开发：** `restart` 停止本脚本启动的进程，重新构建并启动；`setup` 只安装和构建，运行期间不允许执行。这里提供构建后的静态页面，无 HMR／WebSocket；代码变更后重启并刷新浏览器。
- **端口与进程：** 默认 5181，可通过 `-Port` 指定空闲端口；保留 5178 给旧版，不自动抢占端口或终止无关进程。停止前核对进程 ID、启动时间和脚本路径。
- **配置：** 服务端沿用仓库根 `.env` 中的 `DEERMIND_LLM_API_KEY`、`DEERMIND_LLM_MODEL`、`DEERMIND_LLM_BASE_URL`，同名环境变量优先；只允许原先选定的 DeepSeek 官方地址。`/api/live/status` 返回配置是否存在、模型名、课程及 `connected: true`（表示适配器已接线，并非持续的网络健康保证），不返回密钥。实际模型连通性另由真实请求验证。
- **数据：** 新对话单独写入 `.tmp/mvp-prototype-next/sessions/`；浏览器键 `deermind-next-workspace-v1` 保存当前对话索引、草稿、所在页面、展开／收起及课堂进度确认历史。刷新后恢复本轮交流，不新增历史列表。原 `.tmp/mvp-live/` 及旧端口存储不改写；六上旧会话尚未导入，不能自动归入六下。当前仍是本机单一体验者，尚无正式账号认证与多用户权限。
- **家长数据：** 浏览器键 `deermind-next-parent-v1` 独立保存孩子／空间选择、各上下文咨询输入、草稿及复核事项，不读写新学生端数据。5178 旧端口原有草稿、咨询与事项仍保留在那里，本批不自动跨端口导入，也不把新六下学生对话当作旧六上家长示例的记录。

管理员原锁文件组合为 `@vitejs/plugin-vue 5.2.4` 与 `vite 7.3.7`，超出该插件声明的 peer 版本范围。M01 对管理员安装使用 `npm ci --legacy-peer-deps`，保留原文件与版本；已通过本机类型检查、构建和页面走查。此结果仅支持当前预览运行，不表示该依赖组合已获上游兼容承诺，后续工程依赖治理再处理。

## 2. 融合原则与确认方式

学生端保留 V2 的生成式交互：从哪个页面进入活动，右侧就承载该页面；对话、页面切换和收起方式均以 V2 为准。管理员端保留其导航、页面组织及详情结构。旧版家长端单独保留，不套用学生端交互。

迁入的是服务能力、数据保存和必要的业务流程，不是把旧学生界面或旧后台整页塞进 V2。当前 **M01–M07 已按确认范围完成；后台增量按本轮方案实施，见 §7**。课程范围、课堂进度弹窗、题目操作及异常控制的局部按钮均已取得明确确认并接通。M07 按用户要求保留旧家长界面；用户后续已授权新版后台统一模型表达及三个任务；授权覆盖 M08 与 M09/M10/M12 的相关部分，M11 和其他迁入项未据此整体放行。

确认按实际范围生效：例如同意接入会话保存，不意味着同意增加历史面板、改首页卡片或重写章节数据。需要新增或改变可见元素而本清单尚未明确具体形式时，先提供局部变更方案，确认后再实施。即使是原型已有缺陷，也不利用本次迁入授权顺带修改页面。

**M04/M05 的已确认行为：**

- 检测题先显示“开始检测”；开始后在该题输入答案，提交期间禁止重复发送。随堂练习保留原来的直接提交方式。
- 题内未提交答案按题目保存，收起或刷新后恢复；实际提交成功后，题目保留所提交内容，反馈接在对话中。
- 检测中的普通聊天发送及建议按钮暂不可提交，并说明应在题内作答或求助；输入草稿仍可编辑。顶部“结束”仍能退出本次活动。
- “求助”立即把当前检测标记为结束，再请求讲解。未提交的答案草稿留在本机，不发送给模型、不当成作答。即使讲解暂时失败，也不会把检测恢复成独立作答。
- 模型处理中显示“停止”；停止后迟到回复不再展示。失败或停止后可重试；传输结果不确定时重放原请求，模型生成失败时才重新生成该轮回复，两者均不重复追加原输入。
- 停止、错误和重试提示在收起聊天时仍可操作。右侧来源页面与上文保持可见，因此本原型不据此声称已经验证独立作答或正式能力状态。

M02 已迁入结构校验和参考答案不直接下发的约束。V2 文字块在加粗格式转换前先转义 HTML，保留正常视觉效果；不执行任意模型生成的 HTML。

## 7. 新版后台：本轮交付与审阅路径

本轮基于新版绿色侧栏、观测／管理分区、列表详情及瀑布图组件调整，不沿用旧后台整页。学生、家长以及两个原始来源目录未修改。活动事实、分方面判断、定义版本和空间采用共用一个明确的示例数据源；原副本中相互矛盾的旧示例和未接通页面不再作为第二套实现保留，原始基线仍在来源目录及清单中。

访问 `http://127.0.0.1:5181/admin/`。默认“示例走查”，顶部可切换“真实会话”。

1. **章节准备：** 教材管理 → 新增教材／进入教材 → 新增或编辑章节 → 本章映射与目标 → 就地保存。来源核对与可用条件独立呈现，不再审核发布。
2. **判断复核：** 交互审查 → 活动 → 登记查看用途 → 核对实际帮助与评价依据 → 保存意见。确认依据无效时填写原因并停止其及依赖结果的当前使用，历史内容保留。
3. **模型修订：** 领域管理 → 具体领域 → 新增／编辑 Task、Solution 或 KC → 保存。Claim、证据和推断规则在评估模型管理导入定义包，预览后直接保存，不提供通用在线规则编辑器。
